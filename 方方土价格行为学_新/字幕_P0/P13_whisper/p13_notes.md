## 核心主题

**Measured Move（等距测量）**：利用价格结构测算止盈目标位。

---

## 一、Measured Move 核心原理

### 定义
当价格有效突破某个结构（震荡区间、趋势线、双顶/双底）后，行情往往走出与该结构**等距**的第二波。

### 公式
```
目标位 = 突破点 ± 结构高度
```

### 案例：阿里巴巴日线
- 横向震荡区间（最高价到最低价的距离 = 区间高度）
- 突破区间后 → 目标 = 区间高度翻倍
- 大资金在目标位挂限价卖单 → 精准止盈

---

## 二、Measured Move 类型

### 1. 区间突破 Measured Move
```
区间高度 = H - L
突破后目标 = 突破点 ± 区间高度
```

### 2. 双顶/双底 Measured Move
- 双顶反转失败后 → 目标 = 颈线到低点的距离
- 双底突破失败后 → 目标 = 颈线到高点的距离（Wedge 123）

### 3. 缺口作为目标位
- 缺口往往成为后续行情的目标
- 填补缺口 = 目标达成

### 4. 旗形/楔形 Measured Move
- 与区间突破类似
- 旗形高度 → 突破后目标

---

## 三、第一趋势幅度（日内交易）

### 核心规则
> 开盘后的第一波趋势幅度，往往决定了全天的波动范围。

### 应用
- 如果早盘第一波趋势幅度很大 → 全天可能高位震荡
- 如果早盘幅度很小 → 全天可能延续该幅度

---

## 四、止损与止盈策略

### 止损原则
- 止损放在结构之外（不能被轻易触及）
- 多头止损：波段最低点下方
- 空头止损：波段最高点上方

### 止盈原则
- Measured Move 目标 = 客观止盈参考
- "自我感觉良好没有用，关键是要能赚到钱"
- 不固执 → 到达目标就止盈

### 限价单挂单
- 大资金在目标位挂限价卖单
- 当价格到达目标，大量卖单堆积
- 这就是为什么价格经常精准到达目标后回落

---

## 六、实战要点

### ✅ 识别 Measured Move
1. 找到明确的价格结构（区间、双顶/底、旗形）
2. 测量结构高度
3. 从突破点投射目标

### ❌ 不要做的事
1. 不要在目标位不获利了结（固执）
2. 不要凭感觉决定何时止盈
3. 不要忽视目标位的阻力
