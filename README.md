# 美股投资洞察分析

AI 辅助美股投资决策：资料获取、技术分析、辅助决策、概率判断

## 项目简介

这是一个美股量化投资分析系统，包含数据获取、技术指标计算、市场状态分析、策略回测等功能。

## 核心模块

- **P1 (数据获取)**: 获取 K 线数据、市场指标、宏观数据
- **P2 (宏观分析)**: 市场状态分析、多 agent 辩论决策
- **P3 (板块分析)**: 板块轮动分析
- **P4 (选股策略)**: 基于 G1/G2/G3 策略的股票筛选

## 铁律（不变）

- **数据铁律**：交易数据必须来自真实数据源，禁止编造
- **K 线铁律**：禁止以数组位置取价格，必须以 	ime 字段为准

## 快速开始

### 安装依赖

`ash
pip install -r requirements.txt
`

### 运行 P1 每日更新

`ash
cd TradingAgents
python3 fintech/p1/p1_main.py
`

### 仅检查数据新鲜度

`ash
python3 fintech/p1/p1_main.py --check
`
