# P2 / P3 / P4 回测方案

## 目标
找到 P2(择时) + P3(择势) → P4(择股) 权重映射的最优参数组合。

**优化目标**：
- 夏普比率最大化
- 最大回撤 < 15%
- 年化收益 > 15%

---

## 数据需求

### P2 择时所需数据
- SPY日K（2019-01-01 ~ 2026-05-08，至少提前1年计算指标）
- QQQ日K（同上）
- VIX日数据（Yahoo Finance）
- DXY日数据（Yahoo Finance）
- TNX（10年国债收益率）

### P3 择势所需数据
- 8只板块ETF日K：
  - XLF（金融）
  - XLV（医药）
  - ITA（军工）
  - XLY（消费）
  - GLD（贵金属/黄金）
  - GDX（金矿）
  - IBIT（比特币ETF）
  - COIN（Coinbase）
- 可选：SOXX（半导体）

### P4 择股所需数据
- 172只股票日K（已有数据：2019-01-02 ~ 2026-05-08）

## P2 输出变量定义

| 变量名 | 取值范围 | 计算方式 |
|--------|---------|---------|
| `regime_score` | 0-10 | SPY EMA20>EMA50(1) + RSI 40-70(1) + MACD>0(1) + 广度>60%(1) + SOXX多头(1) + VIX<20(1) + DXY<100(1) + NVDA动量>0(0.5) |
| `regime_level` | 大牛/牛/震荡/熊/大熊 | score≥8→大牛，6-7.9→牛，4-5.9→震荡，2-3.9→熊，<2→大熊 |
| `trend_signal` | 延续/加强/减弱 | 连续3日EMA多头排列→延续；RSI从50以下上穿→加强；RSI>70且背离→减弱 |
| `vix_level` | 低/中/高 | VIX<15→低，15-25→中，>25→高 |
| `breadth_pct` | 0-100% | NYSE上涨家数/总家数 |
| `divergence` | 顶背离/底背离/无 | 价格新高但RSI/广度未新高→顶背离 |

### P2 仓位系数决策表

| Regime | 基础仓位 |
|--------|---------|
| 大牛市 (8-10) | 100% |
| 牛市 (6-7.9) | 80% |
| 震荡 (4-5.9) | 50% |
| 熊市 (2-3.9) | 20% |
| 大熊市 (<2) | 0% |

### P2 调整系数

| 条件 | 调整 |
|------|------|
| VIX > 25 | 仓位 × 0.7 |
| 广度 < 40% | 禁止追涨（上限50%） |
| 顶背离出现 | 仓位 × 0.5 |
| 趋势减弱 | G1权重 × 0.8 |
| 趋势加强 | G1权重 × 1.2（上限1.5） |

## P3 输出变量定义

| 变量名 | 取值 | 计算方式 |
|--------|-----|---------|
| `sector_rank[]` | 7个板块排序 | 20日动量排序 |
| `sector_momentum[]` | 每板块20日动量% | (当前价格/20日前价格-1)×100 |
| `money_flow_signal` | 净流入/中性/净流出 | 板块ETF量价共振方向 |
| `rotation_signal` | 领涨切换/轮动/延续 | 领涨板块是否切换 |
| `sector_divergence[]` | 每板块背离标记 | 板块与大盘方向不一致 |

### P3 板块配置权重

- 超配：前3强板块 +5% / +10% / +15% 额外权重
- 低配：后2弱板块 -5% / -10% 权重
- 资金连续3日净流出板块：额外 -10%

## 回测框架

### 数据划分
- **In-sample（参数优化）**：2020-01-01 ~ 2022-12-31（3年，含牛市+熊市）
- **Out-of-sample（验证）**：2023-01-01 ~ 2025-12-31（3年）

### 回测流程
```
for each trading_day T:
  1. 计算 T-1 日的 P2 输出（regime, trend, vix, breadth, divergence）
  2. 计算 T-1 日的 P3 输出（sector_rank, money_flow）
  3. 根据 P2+P3 决策:
     - 仓位系数 = f(regime, vix, breadth, divergence)
     - G1权重 = f(regime, trend_signal)
     - G2权重 = f(regime, rsi_position)
     - G3权重 = f(ml_probability, regime)
     - 板块配置 = f(sector_rank, money_flow)
  4. 按权重分配资金到各策略
  5. 记录 T+1 日收益率
  6. 累积净值

每月汇总:
  - 月度收益率
  - 最大回撤
  - 夏普比率
```

### 交易成本
- 滑点：0.05%
- 手续费：$0.005/股
- 冲击成本：0.1%（大仓位时）

### 评估指标
1. **年化收益率**：CAGR
2. **夏普比率**：年化收益/年化波动率
3. **最大回撤**：MDD
4. **卡玛比率**：CAGR/MDD
5. **胜率**：盈利交易/总交易
6. **盈亏比**：平均盈利/平均亏损
