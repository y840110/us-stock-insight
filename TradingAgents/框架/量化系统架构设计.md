## 三、特征工程层（六大类因子）

### 3.1 市场环境因子（30分）

| 指标 | 计算方法 | 阈值/评分 |
|------|----------|-----------|
| SPY 20EMA > 50EMA | EMA(close, 20) > EMA(close, 50) | +8 |
| SPY 50EMA > 200EMA | EMA(close, 50) > EMA(close, 200) | +8 |
| SPY Close > 20EMA | close / EMA - 1 | +8 |
| SPY ADX > 20 | ADX(14) | +6 |
| VIX < 18 | 直接取值 | +10 |
| VIX 18~25 | 直接取值 | +5 |
| VIX > 25 | 直接取值 | -10 |

**市场环境 = 系统总开关**，市场不过关，个股分析全部作废。

---

### 3.2 Relative Strength 因子（25分）

| 指标 | 计算方法 | 评分 |
|------|----------|------|
| 20日RS > 2 | (Stock_20d_Return / SPY_20d_Return) > 2 | +15 |
| 20日RS 1~2 | 同上，区间 1~2 | +10 |
| 20日RS 0~1 | 同上，区间 0~1 | +5 |
| 20日RS < 0 | 同上 | -10 |
| 65日RS > 1.5 | (Stock_65d_Return / SPY_65d_Return) > 1.5 | +15 |
| 65日RS 1~1.5 | 同上，区间 1~1.5 | +10 |
| 强于行业ETF | Stock_Return > SectorETF_Return | +10 |
| 回调跌幅 < QQQ | (CurrentPrice / 20d_High) < QQQ 同期跌幅 | +5 |

---

### 3.3 趋势结构因子（20分）

| 指标 | 计算方法 | 评分 |
|------|----------|------|
| Close > 20EMA | close > EMA(close, 20) | +5 |
| 20EMA > 50EMA | EMA(20) > EMA(50) | +5 |
| 50EMA > 200EMA | EMA(50) > EMA(200) | +10 |
| 周线20EMA向上 | EMA(weekly_close, 20) 连续3周升高 | +10 |
| 日线RSI 40~70 | RSI(14) 处于健康区间 | +5（避免极值）|

---

### 3.4 成交量 / VSA 因子（15分）

| 指标 | 计算方法 | 评分 |
|------|----------|------|
| 突破放量 | Volume > MA(vol, 20) × 1.5 | +10 |
| 突破极度放量 | Volume > MA(vol, 20) × 2.0 | +15（取代上面）|
| 回调缩量 | 回踩阶段 avg_vol < 上涨阶段 avg_vol × 0.7 | +10 |
| 放量上涨日 | 今日 close > open 且 vol > 1.5×MA | +5 |

---

### 3.5 波动率因子（10分）

| 指标 | 计算方法 | 评分 |
|------|----------|------|
| ATR% = ATR(14) / price | ATR / close × 100 | |
| ATR% 2~5% | 最佳波动率 | +10 |
| ATR% 1~2% | 偏低（可能假突破）| +5 |
| ATR% > 8% | 风险过高 | -10 |

---

### 3.6 价格结构因子（ML 专用，额外计算）

用于深度学习模型输入：

| 特征 | 计算方法 | 用途 |
|------|----------|------|
| CandleBodyRatio | (close-open)/(high-low) | 实体占比 |
| UpperWickRatio | (high-max(open,close))/(high-low) | 上影线占比 |
| LowerWickRatio | (min(open,close)-low)/(high-low) | 下影线占比 |
| Volatility20 | STD(returns, 20) | 20日波动率 |
| Volatility65 | STD(returns, 65) | 65日波动率 |
| HighLowRange | (high-low)/close | 日内振幅 |
| VolumeRatio | vol / MA(vol, 20) | 量比 |
| Returns | close / close_1 - 1 | 单日收益率 |
| MaxDrawdown20 | 从20日高点的最大回撤 | 回撤控制 |

## 四、机器学习层

### 4.1 模型1：市场状态分类器（监督学习）

**目标**：识别 Trend / Neutral / Panic 三种市场状态

**输入特征**：
- SPY 20EMA/50EMA/200EMA 多空排列
- SPY ADX
- VIX 水平
- QQQ vs SPY 相对强弱
- VIX Volatility（VIX的波动率）

**输出**：
- Trend（风险偏好）| Neutral | Panic（风险规避）

**模型**：XGBoost Classifier，轻量可解释

**训练数据标注规则**：
```
Trend:   SPY > 20EMA AND ADX > 25 AND VIX < 20
Panic:   VIX > 30 OR SPY < 200EMA
Neutral: 其他
```

---

### 4.2 模型2：个股胜率预测器（监督学习）

**目标**：预测明日涨/跌/震荡，输出上涨概率

**输入特征**（个股 + 市场叠加）：
- 六大类因子全部数值（标准化）
- 市场状态（one-hot）
- 价格结构特征（实体比/影线比/波动率）
- RS 排名（个股在板块内的百分位）

**输出**：
- P(up) = 上涨概率
- P(down) = 下跌概率
- P(neutral) = 震荡概率

**模型**：Random Forest + Logistic Regression Ensemble

**标签定义**：
```
未来5日：
  涨: close_5d > close × 1.02  → up
  跌: close_5d < close × 0.98  → down
  其他 → neutral
```

---

### 4.3 模型3：盈亏比估算器（回归）

**目标**：估算未来5日合理 R 倍数

**输入特征**：同胜率预测器

**输出**：
- E[R] 期望 R 倍数（正期望为入场依据）

**训练标签**：
```
R = (future_close - entry) / ATR(14)
```

**模型**：XGBoost Regressor

---

### 4.4 模型4：形态识别（可选高级）

**目标**：识别 A类（趋势回踩）/ B类（波动压缩突破）/ C类（恐慌修复）

**方法**：1D-CNN 或 LSTM，处理价格序列

**输入**：过去20日的 OHLCV 标准化序列

**输出**：各类概率 + 二值信号

## 五、决策层

### 5.1 六因子评分（规则驱动）

| 因子 | 权重 | 最高分 |
|------|------|--------|
| 市场环境 | 30 | 30 |
| RS | 25 | 25 |
| 趋势结构 | 20 | 20 |
| VSA | 15 | 15 |
| 波动率 | 10 | 10 |
| **合计** | **100** | **100** |

**决策阈值**：
| 分数 | 动作 | 仓位 |
|------|------|------|
| ≥ 85 | 可交易 | 正常仓 |
| 75 ~ 85 | 轻仓 | 0.5x |
| 60 ~ 75 | 观察 | 0.25x |
| < 60 | 放弃 | 0 |

---

### 5.2 ML 概率验证（概率驱动）

当六因子评分 ≥ 75 时，叠加 ML 验证：

```
IF 六因子评分 ≥ 75 AND ML_P(up) > 0.65 AND E[R] > 1.5:
    → 正常仓（1x）
ELIF 六因子评分 ≥ 75 AND ML_P(up) > 0.55:
    → 轻仓（0.5x）
ELIF 六因子评分 < 60 OR ML_P(up) < 0.50:
    → 放弃
```

---

### 5.3 三种结构过滤（A+/A/B级）

| 结构 | 条件 | 评级 |
|------|------|------|
| 趋势回踩 | 周线向上 + 回踩20EMA + 缩量 + 日线反包 | A+ |
| 压缩突破 | 横盘15天+ + ATR下降 + 突破20日高 + 放量1.5x | A+ |
| 恐慌修复 | VIX>30 + 市场暴跌 + 个股抗跌 + 收复均线 | A |
| 任意满足评分 | 评分≥75 | A |

## 六、止损与盈亏比体系

### 6.1 止损规则

| 入场结构 | 止损位 |
|----------|--------|
| 趋势回踩 | 前低 - 0.5×ATR |
| 波动压缩突破 | 突破K线低点 - 0.5×ATR |
| 恐慌修复 | 最低点 - 0.5×ATR |

**通用规则**：单笔风险 ≤ 1% 账户净值

---

### 6.2 盈亏比估算

```
目标涨幅 = entry_price + ATR × 2.5
最低可接受R = 2.0
E[R] > 2.0 才值得入场
```

## 八、每日分析流水线（run_daily_analysis.py）

```
Step 1: 加载数据
  → 读取 SPY/QQQ/VIX 日K
  → 读取个股日K（持仓股 + 候选池）

Step 2: 计算市场环境（市场层）
  → SPY EMA结构 + ADX + VIX
  → 输出：RiskON / RiskOFF

Step 3: 计算个股特征（全量因子）
  → 对每只股票计算6大类因子数值

Step 4: 六因子评分
  → 输出每只股票的评分（0~100）

Step 5: ML 模型推理
  → 市场分类器 → 当前状态
  → 胜率预测器 → P(up)
  → 盈亏比估算 → E[R]

Step 6: 信号生成
  → 综合评分 + ML + 结构过滤
  → 输出：A+候选 / 观察 / 放弃

Step 7: 更新概率数据库
  → 记录本次信号（供后续统计）
```
