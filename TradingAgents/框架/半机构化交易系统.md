---

## 核心原则

**系统不是为了预测，而是为了找到正期望机会。**

职业交易只关心期望值公式：

```
E = (WinRate × AvgWin) - ((1 - WinRate) × AvgLoss)
```

| 项 | 含义 |
|---|---|
| WinRate | 胜率 |
| AvgWin | 平均盈利 |
| AvgLoss | 平均亏损 |

所有系统设计最后必须回到这个公式。

## 三、Relative Strength（25分）—— 系统核心

**真正强股：下跌时抗跌，上涨时领涨。**

### RS 计算公式

```
RS = Stock Return / SPY Return
```

例：
| 股票 | 20日涨幅 |
|------|----------|
| NVDA | +18% |
| SPY | +4% |

RS = 18 / 4 = 4.5

### 20日 RS 评分

| 条件 | 分数 |
|------|------|
| RS > 2 | +15 |
| RS 1~2 | +10 |
| RS 0~1 | +5 |
| RS < 0 | -10 |

## 附：E 期望值计算模板

```
WinRate =  wins / total_trades
AvgWin  =  total_win_amount / wins
AvgLoss =  total_loss_amount / losses

E = (WinRate × AvgWin) - ((1 - WinRate) × AvgLoss)

判断标准：
  E > 0.5R  → 正期望系统，可执行
  E < 0     → 负期望，必须优化
```
