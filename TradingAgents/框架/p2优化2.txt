# 变盘点识别框架

你目前的模型解决了"当前状态判断"，而变盘点识别本质上是一个**结构性问题**：价格、资金流、市场内部是否在同步恶化？

---

## 核心思路：区分"情绪性回调"与"结构性转弱"

> 健康回踩 = 价格跌，但市场内部结构没坏
> 趋势转弱 = 价格跌，同时内部结构开始松动

---

## 一、价格结构层（最基础）

### 关键问题：这次回调打破了什么？

```
强上涨趋势中的回调分级：

回调幅度          回踩到的位置           性质判断
─────────────────────────────────────────────────
3%~5%        EMA20附近               正常震荡
5%~8%        前高突破位 / EMA50      需要观察
8%~12%       前一个波段低点           警戒线
>12%         EMA200 / 前低被跌穿     趋势转弱信号
```

**更重要的不是跌多少，而是：**
- 反弹时能否创新高？→ 能：结构完好
- 反弹高点是否低于前高？→ 是：开始形成**下降高点**，趋势转弱的早期信号

---

## 二、市场内部宽度层（领先价格的信号）

这是最容易被忽视、但最有效的变盘预警。

| 指标 | 工具 | 健康回调 | 趋势转弱 |
|------|------|----------|----------|
| 涨跌线 | $NYAD / $NAAD | 与SPY同向回调 | **提前于SPY出现顶背离** |
| 强势股占比 | % above MA50 | 回调后快速回升 | 持续低于50% |
| 新高新低 | $NHNL | 新低数量少 | 新低数量快速放大 |
| 分布日 | IBD方法 | 4周内<4天 | **4周内≥4~5个分布日** |

> 💡 **分布日**：SPY 当日收跌 + 成交量高于前日。连续出现说明主力在出货，不是散户恐慌性抛售。

---

## 三、跨市场确认层

价格是结果，资金流向是原因。

```
债券市场（TLT / HYG）
─────────────────────────────────────
TLT上涨 + HYG下跌  →  避险情绪，资金撤出风险资产
                       → 结合SPY大跌 = 趋势转弱警告

HYG跟随SPY下跌幅度有限  →  信用市场没有恐慌
                           → 大概率只是权益市场情绪波动


板块轮动
─────────────────────────────────────
防御板块（XLU / XLP / XLV）领涨  →  资金开始撤防
周期/成长（XLK / XLY / XLC）领跌  →  进攻性资金在退出
```

---

## 四、VIX 结构层（你已有，补充细化）

你目前用VIX作为指标之一，可以进一步细化：

| VIX信号 | 含义 |
|---------|------|
| VIX 急涨至20~25，但快速回落 | 情绪性恐慌，可以买的恐惧 |
| VIX > VIX3M（期限结构倒挂） | 短期恐慌高于长期，趋势转弱预警 |
| VIX持续在25以上无法回落 | 市场进入高波动区制，趋势确认转弱 |
| VVIX（VIX的VIX）同步飙升 | 不确定性本身在放大，避开 |

---

## 五、时间维度（经常被忽略）

```
健康回调的时间特征：
通常 2~3 周内完成，之后创新高

转弱信号的时间特征：
回调时间 > 4~6 周，反弹乏力
─────────────────────────────────────
实战口诀：
"跌得快、弹得快" → 健康
"跌得慢、反弹高点越来越低" → 结构已坏
```

---

## 综合判断矩阵（可量化进你的模型）

```
                     信号方向
维度              健康回踩 (+1)    转弱预警 (-1)
────────────────────────────────────────────────
价格结构          未破前低          破前低/下降高点
宽度(AD线)        同步或领先反弹    顶背离/持续弱
分布日数量        <4天/4周          ≥4天/4周
HYG信用债         小幅下跌          大幅跟跌/领跌
板块轮动          进攻性板块仍强    防御板块领涨
VIX结构           未倒挂            VIX > VIX3M
回调持续时间      <3周              >4周无新高

得分 ≥ +3  →  健康回踩，可加仓
得分 0~2   →  观望，减少新仓
得分 ≤ -1  →  趋势转弱，降仓防守
```

---

## 一句话总结

> **价格是滞后的，变盘点的本质是：市场内部结构（宽度、资金流、信用）是否在价格大跌之前或同步出现了系统性松动。** 单看SPY跌了多少是不够的，要看"是谁在跌、资金去了哪里、主力是否在出货"。

你现有的三因子模型（20日涨幅 + EMA20 + VIX）可以在此基础上**增加宽度指标（AD线 / % above MA50）和信用债（HYG）**，基本就能覆盖大多数变盘场景。
