## 策略 A：超跌反弹（Mean Reversion）— 辅助参考

> **角色**：在震荡/走弱市场中提供超跌信号参考；在牛市中作为 Watch 信号
> **历史回测**：胜率 ~54%（实际），低于理论值71%（牛市环境下失效）

### 入场条件（必须满足 ≥ 4 项，含所有 must=true 项）

| 条件ID | 指标 | 阈值 | 说明 | 必须 |
|--------|------|------|------|------|
| `rsi` | 日线 RSI(14) | ≤ 32 | 超卖区，反弹空间充足 | ✅ |
| `ema_dev` | 价格高于 20EMA 幅度 | ≤ +3% | 偏离不过远，止损可控 | — |
| `vol_ratio` | 今日量 / 20日均量 | ≤ 0.80× | 量能萎缩 = 抛压减弱 | ✅ |
| `wick_pct` | 下影线 / K线总高度 | ≥ 40% | 长下影线 = 空方被拒绝 | ✅ |
| `vix` | VIX 指数 | ≤ 27 | 过度恐慌时假信号增多 | — |

**入场价**：`信号K线最高价`（次日突破确认后入场）
**止损价**：`信号K线最低价 − 0.3 × ATR(14)`
**目标价**：`入场价 + 2.2 × (入场价 − 止损价)`

## 策略 B：量价突破（Volume Breakout）— 辅助参考

> **角色**：在超强牛市/一般牛市中作为强势标的的突破信号参考
> **历史回测**：胜率 ~54%（实际），均值回归策略在趋势牛市中天然失效

### 入场条件（必须满足 ≥ 4 项，含所有 must=true 项）

| 条件ID | 指标 | 阈值 | 说明 | 必须 |
|--------|------|------|------|------|
| `breakout_pct` | 突破 15 日高点幅度 | 0% ~ 1.5% | 刚突破，追涨幅度不过大 | ✅ |
| `vol_ratio` | 突破量 / 20日均量 | ≥ 2.0× | 必须有强烈量能驱动 | ✅ |
| `rsi` | 日线 RSI(14) | 45 ~ 68 | 动能充足但未超买 | ✅ |
| `ema50_dev` | 价格高于 50EMA 幅度 | ≥ 0%（站上） | 大趋势向上是前提 | ✅ |
| `atr_ratio` | 当前ATR / 20日ATR均值 | ≤ 0.85× | 突破前波动率收缩 = 蓄势 | — |

**入场价**：`15日高点 + 0.1 × ATR(14)`
**止损价**：`突破前10日最低价`
**目标价**：`入场价 + 2.0 × (入场价 − 止损价)`

## 策略 C：VWAP 复归（VWAP Reclaim）— 辅助参考

> **角色**：震荡市场中高抛低吸的精确入场参考
> **注意**：需5分钟K线，日线策略暂不支持；当前版本仅供参考

| 条件ID | 指标 | 阈值 | 说明 | 必须 |
|--------|------|------|------|------|
| `vwap_dev` | 价格偏离 VWAP | ±1.5% 以内 | 刚复归，偏离不过远 | ✅ |
| `vol_ratio` | 复归K线量 / 近10根均量 | ≥ 1.8× | 量能确认复归有效性 | ✅ |
| `spy_above` | SPY/QQQ 站上各自 VWAP | 是=1，否=0 | 大盘方向一致才做，逆势不做 | ✅ |

**入场价**：`复归K线收盘价`
**止损价**：`VWAP 价格 − 1.0 × ATR`
**目标价**：`入场价 + 2.0 × (入场价 − 止损价)`

## 策略 D：趋势回踩（Trend Pullback）— 牛市专用 ⭐NEW

> **角色**：填补策略A/B在趋势牛市中失效的空白，是**牛市中的核心SETUPS策略**
> **设计依据**：回测发现牛市中量价突破（策略B）信号少，但趋势回踩机会频繁
> **状态适用**：🚀超强牛市 / 📈一般牛市；❌震荡/走弱/大跌禁用

### 入场条件（必须满足 ≥ 4 项，含所有 must=true 项）

| 条件ID | 指标 | 阈值 | 说明 | 必须 |
|--------|------|------|------|------|
| `market_state` | 市场状态 | 超强牛市 或 一般牛市 | 大盘必须处于上升趋势 | ✅ |
| `price_ma20` | 价格 vs MA20 | 在MA20上方，偏离≤+12% | 确认处于上升趋势 | ✅ |
| `rsi` | 日线 RSI(14) | 40 ~ 60 | 健康回调区间，非超买 | ✅ |
| `vol_ratio` | 今日量 / 20日均量 | ≤ 0.80× | 缩量回踩 = 主力未出货 | ✅ |
| `wick_pct` | 下影线 / K线总高度 | ≥ 35% | 下影线 = 买方拒绝 | — |
| `spx_state` | SPY 状态 | 非大跌日（评分>-4） | 大盘当日不能破位 | ✅ |
| `gap` | 当日跳空 | 无向下跳空 >2% | 排除持续下跌中的"假回踩" | — |

### 入场逻辑

```
IF market_state in [SUPERBULL, BULL]:
    IF price_above_ma20 AND rsi_40_60 AND vol_ratio <= 0.80:
        IF wick_pct >= 35% OR price_touches_ma20:
            SETUP_D = TRIGGERED
            # 精确入场由 ML 信号确认
```

**入场价**：`信号K线最高价 + 0.1×ATR`（次日突破确认）
**止损价**：`信号K线最低价 − 0.3×ATR` 或 `MA20 - 0.5×ATR`（两者取较高者）
**目标价**：`入场价 + 2.0×(入场价−止损价)`（牛市目标可适当放宽至2.5:1）
**持仓上限**：牛市状态下最多持有5个策略D仓位

### 策略D vs 策略B 对比

| 维度 | 策略D 趋势回踩 | 策略B 量价突破 |
|------|--------------|--------------|
| 市场环境 | 牛市/超强牛市 | 牛市（偏强势）|
| 基础逻辑 | 顺势回踩 | 突破追涨 |
| RSI 区间 | 40~60 | 45~68 |
| 量能要求 | 缩量（≤0.80×）| 放量（≥2.0×）|
| ATR 要求 | 无特殊 | 收缩（≤0.85×）|
| 止损位置 | MA20 或 信号日低点 | 突破前最低点 |
| 目标 | 2.0:1~2.5:1 | 2.0:1 |

## 与 ML 决策层的关系（v2）

```
策略D触发 → ML P_up > 55% + E[R] > 1.0 → LONG 正常仓
策略D触发 → ML P_up 50~55% OR E[R] 0.7~1.0 → WATCH 半仓
策略D触发 → ML P_up < 50% → WATCH/放弃（不否决，只降低优先级）
```

**策略D不作为否决条件**，只作为 ML 信号通过后的入场优化。

## 仓位管理规则（通用）

### 公式

```
风险金额 = 总资金 × 风险百分比（按市场状态，见下表）
股数 = floor(风险金额 ÷ 每股票止损距离)
每股止损距离 = 入场价 − 止损价
```

### 分市场状态的风险百分比

| 市场状态 | 单笔风险 | 说明 |
|---------|---------|------|
| 🚀 超强牛市 | 1.5% | 全力进攻 |
| 📈 一般牛市 | 1.0% | 稳健做多 |
| ↔️ 震荡市场 | 0.75% | 快进快出 |
| ⬇️ 市场走弱 | 0.5% | 极度保守 |
| 🔴 市场大跌 | 0% | 仅反向ETF |

### 期望值计算

```
EV = 胜率 × 目标盈利 − 败率 × 最大亏损
入场条件：EV > 0
```

### 分批止盈（通用）

| 条件 | 操作 |
|------|------|
| 价格触及 入场价 + 1×止损距离 | 减仓 1/3（收回本金） |
| 价格触及 入场价 + 2×止损距离 | 再减仓 1/3 |
| 之后 | 用 MA20 移动止损 |

## 与 CRO 战略层的关系（v2）

CRO 五级市场状态机（见 `框架优化方案_v2.md`）是**战略层**，决定：
- 当前市场状态（超强牛市/一般牛市/震荡/走弱/大跌）
- 整体风险敞口（单笔风险百分比）
- 哪些 SETUPS 策略适用

量化 SETUPS（尤其是策略D）是**战术层**，负责：
- 精确入场点计算（在大盘状态确认后）
- 止损/目标量化
- 仓位精确计算

两者结合：
```
CRO 判断市场状态 → 决定风险敞口
    ↓
ML P_up + E[R] 判断个股方向 → 决定是否操作
    ↓
SETUPS D 提供精确入场点 → 优化入场时机
```
