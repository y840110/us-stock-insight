# 短线操作全流程指南

> 日期：2026-05-09 | 版本：v1.0
> 适用账户：短线账户（20%资金）| 操作频率：每天最多3笔

---

## 盘前准备（09:00 - 09:25）

```
【必须完成】

1. 查看大盘状态
   SPY > MA20？→ 多头允许
   QQQ > MA20？→ 多头允许
   ADX > 20？→ 有趋势才做

2. 查看 VIX
   VIX < 20 → 正常操作
   VIX 20-25 → 降低仓位
   VIX > 25 → 禁止开新仓

3. 确认今日无重大宏观数据
   有 CPI / FOMC / 非农 → 当日不做ORB

4. 查看持仓情况
   昨天仓位 → 是否需要止损/止盈
   是否触发连续亏损休市规则

5. 决定今日模型优先级
   大盘强势 → 模型A（EMA回踩）
   大盘震荡 → 模型C（VWAP支撑）
   方向明确 + 开盘波动大 → 模型B（ORB）
```

**盘前检查清单：**
```
[ ] SPY > MA20
[ ] QQQ > MA20
[ ] VIX < 25
[ ] 今日无重大数据
[ ] 账户状态：可交易 / 休市中
[ ] 今日已交易 X/3 笔
```

## 盘中操作（09:30 - 15:30）

### 三个时段的不同策略

#### 09:30 - 10:00：ORB 时间窗口

```
【只做模型B：开盘30分钟突破】

这30分钟是全市场流动性最高的时候

ORB 操作步骤：
1. 记录 SPY 开盘方向
2. 确定自己的操作方向（只做一个方向）
3. 观察目标标的的开盘区间
4. 10:00 之后等待突破确认
5. 突破确认 → 入场
6. 未突破 → 放弃，等待下一个模型

⚠️ 禁止：
  - 09:30 追涨杀跌
  - 在10:00前提前入场
  - 无信号硬做
```

#### 10:00 - 15:00：主要操作时间

```
【三种模型都可以】

模型A：EMA回踩（最优先）
  → 等待价格回踩 EMA20 / VWAP
  → 出现锤子线 / 吞没
  → 缩量确认
  → 入场

模型C：VWAP支撑
  → 价格急跌到 VWAP 附近
  → 出现 PA 信号
  → RSI < 40
  → 缩量
  → 入场

入场后：
  → 朝有利方向 → 移动止损
  → 到达 1:1 → 减仓1/3
  → 触及止损 → 立即走
```

#### 15:00 - 15:30：收尾时间

```
【只平仓，不开新仓】

15:00之后：
  ❌ 禁止开新仓
  ✅ 处理持仓

持仓处理：
  → 有盈利 → 主动止盈
  → 在成本价附近 → 用移动止损保护
  → 小亏 → 止损走了，不留恋

收盘前5分钟：
  → 有盈利的仓位全部平掉
  → 不博隔夜波动
```

## 盘后复盘（16:00 - 17:00）

```
【每天必须完成，这是最重要的习惯】

复盘清单：

1. 今日交易记录
   - 做了哪几笔？
   - 每笔的模型是什么？
   - 入场评分是多少？
   - 结果盈亏？

2. 今日错误
   - 哪笔交易不应该做？
   - 止损执行是否到位？
   - 有没有违反规则？

3. 市场观察
   - 大盘今日方向？
   - 哪个模型出现机会最多？
   - 哪个板块最强？

4. 明日计划
   - 大盘预期？
   - 关注哪几个标的？
   - 哪个模型可能有机会？

5. 记录到 Excel
   打开 短线交易日志.xlsx
   填写今日所有交易（不管盈亏）
```
