# 「高胜率・低频・低回撤」美股波段框架（实战版）

> 核心理念：不是"分析更多"，而是"严格过滤"
> 框架版本：v1.0
> 建立日期：2026-05-09
> 适用市场：美股日线/周线波段
> 持仓周期：3天～6周
> 风险偏好：低（不博超额收益）

---

## 核心思想

**旧思维**：发现机会 → 找理由确认 → 操作
**新思维**：先过滤掉 90% 垃圾机会 → 剩下的才分析 → 严格条件才操作

> 低风险高胜率的本质不是"预测更准"，而是"只在优势巨大时下注"。

---

## 五层过滤结构

```
第一层：市场环境过滤（Beta安全是前提）
         ↓（通过才进入第二层）
第二层：股票质量过滤（只交易市场最强10%）
         ↓（通过才进入第三层）
第三层：趋势结构确认（只允许三种形态）
         ↓（通过才进入第四层）
第四层：低风险入场（绝不追高，确认后回踩）
         ↓（通过才进入第五层）
第五层：风险收益过滤（盈亏比≥2.5:1）
         ↓（全部通过才操作）
执行交易
```

**五层任一层失败 → 直接放弃**

## 第一层：市场环境过滤

### 1.1 大盘趋势条件

**同时满足才允许开仓：**

| 条件 | 要求 | 说明 |
|------|------|------|
| SPY 周线 | 20周均线向上 | 大方向安全 |
| SPY 日线 | 收盘在20日均线上方 | 短期趋势向上 |
| QQQ 日线 | 收盘在20日均线上方 | 科技/成长方向确认 |
| ADX | > 20 | 有明确趋势（非震荡） |
| VIX | < 30 | 无恐慌爆炸 |

**任一不满足 → 禁止开新仓**

### 1.2 禁止交易日（绝对红线）

以下情况无论分析多漂亮，一律禁止交易：

| 禁止类型 | 原因 |
|---------|------|
| CPI 前一天 | 波动不可预测 |
| FOMC 周 | 容易假突破/急跌 |
| 财报前 3 天 | Gamma 风险巨大，期权价格失真 |
| 非农数据日 | 宏观冲击 |
| VIX > 30 | 系统性风险过大 |
| 大盘放量破位日 | 趋势可能逆转 |

### 1.3 市场环境输出格式

```
【市场环境】
SPY 趋势: 多头 / 空头 / 不满足
QQQ 趋势: 多头 / 空头 / 不满足
ADX: XX（>20=有趋势）
VIX: XX（<30=安全）
是否允许交易: YES / NO
```

## 第二层：股票质量过滤

> 只交易市场最强的 10%。分析垃圾股票是亏钱的主要原因之一。

### 2.1 强 Relative Strength（最核心因子）

**必须同时满足：**

| 条件 | 要求 | 含义 |
|------|------|------|
| 20日 RS vs SPY | 持续强于 SPY | 战胜大盘 |
| 20日 RS vs 行业ETF | 强于行业 ETF | 战胜板块 |
| 回调时表现 | 跌幅 < QQQ 跌幅 | 跌时抗跌 |

**RS 计算方式：**
```
RS_20d = (个股20日涨跌幅) - (SPY 20日涨跌幅)
RS_65d = (个股65日涨跌幅) - (SPY 65日涨跌幅)
```

**RS 评级：**
- RS > 1.15（强于大盘15%+）→ A级
- RS 1.05~1.15（强于大盘5-15%）→ B级
- RS 0.95~1.05（与大盘同步）→ C级
- RS < 0.95（弱于大盘）→ 直接淘汰

### 2.2 机构偏好

**必须满足：**

| 条件 | 要求 |
|------|------|
| 日均成交额 | ≥ 5亿美元 |
| 机构持仓比例 | > 60% |
| 股票市值 | ≥ 100亿美元 |

**原因**：大资金会维护趋势，机构持仓高的股票趋势更稳定

### 2.3 行业热度

**只做市场主线行业：**

优先：AI / 半导体 / 云计算 / 网络安全 / 医疗创新

**回避**：处于长期下降通道的夕阳行业

### 2.4 股票质量输出格式

```
【股票质量】
Relative Strength 评级: A / B / C（低于B直接淘汰）
RS 20日: +XX%（对SPY）
RS 65日: +XX%（对SPY）
日均成交额: $X亿（<5亿直接淘汰）
机构持仓: XX%（<60%谨慎）
行业: XX（主线/非主线）
综合评级: 通过 / 淘汰
```

## 第三层：趋势结构确认

> 只允许三种高胜率结构。删除大量主观分析。

### 三种允许形态

#### A类：趋势回踩（最高优先级）

**特征：**
- 周线趋势向上（HH/HL 完整）
- 日线回踩 20EMA 或 50EMA
- 缩量回调（机构未出货）
- 放量反弹确认

**机构最喜欢这种结构。** 稳定性最高。

**确认条件：**
```
1. 日线收盘价在 20EMA 附近（±3%）
2. 成交量 < 20日均量的 60%
3. 出现 PA 反转信号（锤子线 / Bullish Engulfing）
4. 下一日放量阳线确认
```

#### B类：平台突破

**特征：**
- 横盘整理 ≥ 3 周
- 波动率压缩（布林带收口）
- 成交量逐步下降（蓄势）
- 突破日放量（确认）

**本质：波动率扩张行情。**

**确认条件：**
```
1. 横盘区间：价格波动 < 15%
2. 整理天数 ≥ 15 交易日
3. 突破日成交量 > 1.5倍 20日均量
4. 突破后 3 日内不跌回平台
```

#### C类：恐慌后修复

**特征：**
- 指数/板块恐慌性急跌
- 该股跌不动（强于大盘）
- 快速收复关键均线
- Put/Call 极度恐慌（PCR > 1.2）

**本质：超跌反转。低风险高赔率。**

**确认条件：**
```
1. 指数急跌 ≥ 3%（市场恐慌）
2. 该股跌幅 < 指数跌幅的 50%
3. 3 日内收复 MA20
4. PCR > 1.2（恐慌见顶信号）
```

### 禁止的形态

以下形态即使其他条件满足，**直接淘汰**：
- 连续加速上涨后（RSI > 80 超过 10 天）
- 高位宽幅震荡（可能是派发）
- 假突破后再假突破（双重陷阱）
- 成交量背离（价涨量跌）

### 3.1 趋势结构输出格式

```
【趋势结构】
当前结构: A类趋势回踩 / B类平台突破 / C类恐慌修复 / 禁止
周线趋势: 多头 / 空头（空头直接淘汰）
日线位置: 突破 / 回踩 / 整理 / 禁止
放量确认: YES / NO
结构评级: A / B / 淘汰
```

## 第四层：低风险入场

> 看对了，但买点垃圾，是亏钱的第二大原因。

### 4.1 入场原则

**绝不追高。**

只做"确认后的回踩"：
- 突破第一天不追
- 等回踩确认再进
- 假突破大部分死在第一天追高

### 4.2 两种最佳入场模型

#### 模型1：EMA回踩（最优先）

```
入场条件：
  1. 趋势向上（MA5 > MA10 > MA20）
  2. 价格回踩 20EMA（±3%以内）
  3. 成交量 < 20日均量 60%
  4. 出现 PA 反转 K 线（锤子线 / Engulfing）
  5. 下一日放量阳线确认

入场点：锤子线低点下方 1% 或 Engulfing 收盘价
止损点：锤子线低点 或 平台低点（取较低者）
```

#### 模型2：平台突破回踩

```
入场条件：
  1. 放量突破平台（成交量 > 1.5倍 20日均量）
  2. 突破后回踩平台（不跌回平台内部）
  3. 回踩缩量（< 20日均量 60%）
  4. 再次放量阳线确认

入场点：平台高点上方 1% 或 回踩低点
止损点：平台下沿下方 1%
```

### 4.3 入场输出格式

```
【入场计划】
入场模型: EMA回踩 / 平台突破回踩 / 禁止追高
入场价位: $XXX
入场日期: YYYY-MM-DD
止损价位: $XXX（-X.X%）
止损理由: 前低 / 平台下沿 / MA20
```

## 第五层：风险收益过滤（灵魂层）

> 不是"能不能涨"，而是"值不值得赌"。

### 5.1 盈亏比要求

**盈亏比必须 ≥ 2.5:1，否则不做**

```
盈亏比 = 潜在涨幅 / 潜在跌幅

计算方式：
  潜在涨幅 = 第一目标价 - 入场价
  潜在跌幅 = 入场价 - 止损价
```

**最低标准：**
- 盈亏比 ≥ 2.5:1 → 正常仓位
- 盈亏比 2.0~2.5:1 → 轻仓（半仓）
- 盈亏比 < 2.0:1 → 直接放弃

### 5.2 止损规则

**必须技术止损，不用固定百分比**

| 结构类型 | 止损位置 |
|---------|---------|
| 趋势回踩 | 前低（HH 回调低点） |
| 平台突破 | 平台下沿 |
| 恐慌修复 | 恐慌当日最低点 |

**绝不使用**：固定 5%、固定 8%（不同股票波动率不同）

### 5.3 止盈规则

**分批止盈：**

| 目标 | 减仓比例 |
|------|---------|
| 1:1 时 | 减仓 1/3（收回本金） |
| 2:1 时 | 再减仓 1/3 |
| 移动止损 | 之后用 MA20 追踪 |

### 5.4 风险收益输出格式

```
【风险收益】
入场价: $XXX
止损价: $XXX（-X.X%）
第一目标: $XXX（+X.X%）
第二目标: $XXX（+X.X%）
盈亏比: X.X:1（<2.5:1直接放弃）
仓位建议: 正常 / 半仓 / 放弃
```

## 综合评分系统

### 评分权重

| 因子 | 权重 |
|------|------|
| 市场环境 | 30% |
| RS 强度 | 25% |
| 趋势结构 | 20% |
| 成交量/VSA | 15% |
| 波动率结构 | 10% |

### 评分标准

| 总分 | 操作 |
|------|------|
| ≥ 85 | 可交易（正常仓位） |
| 70 ~ 85 | 轻仓观察 |
| < 70 | 直接放弃 |

### 一票否决（任一触发 → 放弃）

| 否决项 | 条件 |
|--------|------|
| 财报前 | 3 个交易日内 |
| 大盘跌破 | 日线 MA20 |
| 放量长上影 | 涨幅 > 5% 但收长上影 |
| IV 异常高 | IV Rank > 70% |
| 板块转弱 | 行业 ETF 跌破 MA20 |
| RSI 极度 | RSI > 80 超过 10 天 |

## 期权策略模块（简化版）

> Gamma Squeeze 低频且危险，不适合低风险系统。

### 适合低风险系统的期权策略

| 策略 | 适用场景 | 说明 |
|------|---------|------|
| Call Debit Spread | 趋势上涨 | 降低成本，锁定利润 |
| Put Debit Spread | 趋势下跌 | 熊市保护 |
| Cash Secured Put | 想低吸股票 | 收权利金降低成本 |
| Covered Call | 已有持仓 | 增强收益 |

### 禁止的期权操作

- 裸买 OTM 彩票期权
- 0DTE（极度高风险）
- 赌财报（IV crush 陷阱）

### 期权采用条件

必须同时满足：
1. 置信度评分 ≥ 85
2. 趋势概率上涨 ≥ 60%
3. IV Rank ≤ 40%（期权不要太贵）

### 期权输出格式

```
【期权计划】
策略: Call Debit Spread / Put Debit Spread / 不适用
标的: {ticker}
行权价: $XXX
到期日: YYYY-MM-DD
权利金成本: $XXX/股
最大盈利: $XXX/股
盈亏平衡点: $XXX
执行条件: 满足 / 不满足（说明原因）
```

## 核心理念总结

| 旧思维 | 新思维 |
|--------|--------|
| 发现机会就分析 | 先过滤90%垃圾机会 |
| 所有指标同时投票 | 市场状态先行，因子按环境调用 |
| 追突破 | 确认后回踩才入 |
| 盈亏比合适就做 | 盈亏比≥2.5:1才做 |
| 分析完就操作 | 否决过滤器有一条触发就停 |
| 尽量多交易 | 一个月只出手2-5次 |
| 追求暴利 | 追求稳定复利 |

---

**三条最高原则：**
1. 市场环境是前提（SPY + QQQ 同时满足条件才看个股）
2. 只做最强10%的股票（RS + 机构参与 + 行业主线）
3. 五层全部通过才交易，一票否决直接放弃

---

> 一个月只出手 2~5 次，但胜率明显提升。
> 这才符合低风险偏好的核心目标。
