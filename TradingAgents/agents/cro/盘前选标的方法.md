# 盘前选标的方法

> 版本：v1.0 | 日期：2026-05-09
> 目的：开盘前筛选今日值得关注的标的

---

## 选股原则

```
短线选标的不需要多，每天 2-3 只就够了

优先选择：
  1. 流动性好的 ETF（SPY / QQQ）
  2. 超大型股（AAPL / MSFT / GOOGL / NVDA）
  3. 今日有催化剂的股票（财报 / 新闻 / 数据）

禁止选择：
  - 小市值 / 低流动性
  - 开盘涨跌超过 5%（波动太大）
  - 新闻面不明确的标的
```

---

## 第一步：判断大盘方向（必须做）

```
目的：确定今天是做多还是做空，或者休息

工具：
  1. 标普期货（ES）→ 判断 SPY 方向
  2. 纳斯达克期货（NQ）→ 判断 QQQ 方向
  3. VIX → 判断波动率

判断标准：

  【强势多头日】
  标普期货 > 昨收 + 0.5%
  VIX < 18
  → 今日适合顺势做多 ORB

  【弱势空头日】
  标普期货 < 昨收 - 0.5%
  VIX > 25
  → 今日禁止 ORB，多看少动

  【震荡日】
  标普期货在昨收 ±0.5% 区间
  VIX 18-25
  → 今日适合模型A（EMA回踩）和模型C（VWAP支撑）
```

---

## 第二步：筛选关注标的（每天 5-8 只）

### 渠道一：盘前涨幅榜（最重要）

```
网站：https://finance.yahoo.com → Market Watch → Pre-Market

筛选条件：
  1. 盘前涨跌幅：+2% ~ +5%（太强不追）
  2. 盘前涨跌幅：-2% ~ -5%（太弱不抄）
  3. 成交量：盘前成交量 > 100 万股

为什么要在这个范围：
  → +2% 以内：可能有延续性
  → +5% 以上：要么买不到，要么是陷阱
  → -2% 以内：可能是正常回调
  → -5% 以下：可能有负面新闻，不接飞刀
```

### 渠道二：持仓股 + 熟悉的标的

```
短线不需要到处找标的

固定关注池（根据你的长线仓位）：
  → 如果持有 GLW / UBER / WOLF → 关注这三只的短线机会
  → 熟悉的标的更容易判断结构

好处：
  → 你已经了解它的日线结构
  → 知道它的支撑压力在哪
  → 减少盘前分析时间
```

### 渠道三：板块ETF辅助判断

```
当日强势板块（盘前可以判断）：
  科技 → QQQ / SOXX
  金融 → XLF
  能源 → XLE
  医疗 → XLV

用法：
  → 如果 SOXX 盘前最强 → 关注 ANET / AVGO / AMAT
  → 如果 XLF 盘前最强 → 关注 JPM / GS
```

## 第三步：盘前快速分析（每只 30 秒）

```
对每只候选标的，做最简单的检查：

1. 现在价格在哪？
   → 在 MA20 上方？（多头）
   → 在 MA20 下方？（空头）
   → 在 MA20 附近震荡？（休息）

2. 今日适合哪个模型？
   → 价格在 MA20 上方 + 回踩 → 模型A
   → 价格急跌到支撑 → 模型C
   → 开盘有明确方向 → 模型B

3. 今日有没有数据/财报？
   → 有 → 放弃（波动不可预测）

结论：
   → 每只标的 30 秒，决定：
     ✅ 关注（可以做）
     ❌ 跳过（不符合条件）
```

## 盘前选标的常见错误

```
❌ 选的太多（超过5只）
  → 顾不过来，容易乱

❌ 选小市值股票
  → 流动性差，滑点大，进出困难

❌ 选波动太大的（涨跌超过10%）
  → ORB止损不好设

❌ 选不熟悉的标的
  → 盘前分析时间不够，容易判断失误

❌ 凭感觉选
  → 一定要有明确的筛选条件
```

## 每日盘前 10 分钟流程

```
09:00-09:05  大盘方向
  → 标普期货 + VIX
  → 判断今日是否适合操作

09:05-09:15  筛选关注标的
  → 盘前涨幅榜 → 选 2-3 只
  → 持仓熟悉的标的 → 选 1-2 只
  → 每天最多 5 只

09:15-09:25  快速分析
  → 每只标的 30 秒
  → 确定关键位
  → 决定适合哪个模型

09:25          准备就绪，等待开盘
```
