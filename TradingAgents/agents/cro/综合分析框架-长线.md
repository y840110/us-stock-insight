## 总开关：市场状态识别

**所有分析的起点。决定哪些因子权重高，哪些禁用。**

### 判断标准（量化）

```python
# ADX 计算
ADX = Wilder平滑(DMI) * 100

# 市场状态判断
if ADX > 25 and 价格 > 200MA:
    状态 = "强趋势上行"
elif ADX > 25 and 价格 < 200MA:
    状态 = "强趋势下行"
elif ADX < 20 and 价格在布林带内:
    状态 = "震荡区间"
else:
    状态 = "高波动破位"  # 缩小仓位或观望
```

### 市场状态 × 因子权重矩阵

| 维度 | 强趋势上行 | 震荡区间 | 高波动破位 |
|------|-----------|---------|-----------|
| 趋势维度（道氏/Wyckoff/波浪） | **高权重** | 禁用 | 低权重 |
| 动量维度（RSI/TD） | 禁用 | **高权重** | 低权重 |
| 量价维度（VSA/机构资金） | **高权重** | 中权重 | **高权重** |
| 结构维度（形态/PA） | 中权重 | **高权重** | 禁用 |
| 情绪维度（IV/GEX） | 低权重 | 中权重 | **高权重** |

### 输出格式

```
═══════════════════════════════════════
【市场状态】
日期: YYYY-MM-DD
SPY: $XXX（20日均线上方/下方）
ADX: XX（>25=趋势 / <20=震荡）
VIX: XX（>30=恐慌）
当前状态: 强趋势上行 / 震荡区间 / 高波动破位
适用策略: 趋势跟随 / 均值回归 / 观望
═══════════════════════════════════════
```

## 第一层：市场环境过滤

### 1.1 大盘条件（同时满足）

| 条件 | 要求 |
|------|------|
| SPY 周线 | 20周均线向上 |
| SPY 日线 | 收盘 > 20日均线 |
| QQQ 日线 | 收盘 > 20日均线 |
| ADX | > 20（有明确趋势） |
| VIX | < 30（非恐慌状态） |

**任一不满足 → 第一层失败 → 直接放弃**

### 1.2 禁止交易日

以下情况无论分析多漂亮，**绝对禁止开仓**：

| 禁止类型 | 原因 |
|---------|------|
| CPI 前一天 | 波动不可预测 |
| FOMC 周 | 容易假突破/急跌 |
| 财报前 3 天 | Gamma 风险巨大 |
| 非农数据日 | 宏观冲击 |
| VIX > 30 | 系统性风险过大 |
| 大盘放量破位日 | 趋势可能逆转 |

## 第二层：股票质量过滤

> 只交易市场最强 10%。分析垃圾股票是亏钱的主要原因之一。

### 2.1 Relative Strength（最核心因子）

**计算方式：**
```python
RS_20d  = 个股20日涨跌幅 - SPY 20日涨跌幅
RS_65d  = 个股65日涨跌幅 - SPY 65日涨跌幅
RS_vs_sector = 个股20日涨跌幅 - 行业ETF 20日涨跌幅
```

**评级标准：**

| 评级 | RS_20d | 含义 |
|------|---------|------|
| A级 | > 15% | 强于大盘 15% 以上 |
| B级 | 5%~15% | 强于大盘 5-15% |
| C级 | -5%~5% | 与大盘同步 |
| 淘汰 | < -5% | 弱于大盘 |

**低于 B 级 → 直接淘汰**

### 2.2 机构偏好

| 条件 | 要求 |
|------|------|
| 日均成交额 | ≥ 5亿美元 |
| 机构持仓比例 | > 60% |
| 市值 | ≥ 100亿美元 |

### 2.3 行业热度

**只做市场主线行业**：AI / 半导体 / 云计算 / 网络安全 / 医疗创新

**输出格式：**
```
【股票质量】
RS 20日（对SPY）: +XX% → 评级 A/B/C
RS 65日（对SPY）: +XX%
RS vs 行业ETF: +XX%
日均成交额: $X亿（<5亿淘汰）
机构持仓: XX%
行业: XX（主线/非主线）
综合评级: 通过 / 淘汰
```

## 第三层：趋势结构确认

> 只允许三种高胜率结构。删除复杂主观分析。

### 三种允许形态

#### A类：趋势回踩（最优先）

```
特征：
  - 周线趋势向上（HH/HL 完整）
  - 日线回踩 20EMA 或 50EMA（±3%以内）
  - 缩量回调（成交量 < 20日均量 60%）
  - 出现 PA 反转 K 线（锤子线 / Bullish Engulfing）

确认条件（必须全部满足）：
  1. 日线收盘在 20EMA 附近（±3%）
  2. 成交量 < 20日均量的 60%
  3. 出现锤子线或 Engulfing
  4. 下一日放量阳线确认
```

#### B类：平台突破

```
特征：
  - 横盘 ≥ 3 周（15个交易日）
  - 波动率压缩（布林带收口）
  - 成交量逐步下降
  - 突破日放量

确认条件：
  1. 横盘区间波动 < 15%
  2. 整理天数 ≥ 15 交易日
  3. 突破日成交量 > 1.5倍 20日均量
  4. 突破后 3 日内不跌回平台
```

#### C类：恐慌后修复

```
特征：
  - 指数恐慌性急跌（≥3%）
  - 该股跌幅 < 指数跌幅的 50%
  - 3日内收复 MA20
  - PCR > 1.2（恐慌见顶信号）

本质：超跌反转。低风险高赔率。
```

### 禁止的形态

以下形态**直接淘汰**：
- RSI > 80 超过 10 天（连续加速）
- 高位宽幅震荡（可能是派发）
- 假突破后再次假突破
- 成交量背离（价涨量跌）

## 第四层：低风险入场

> 看对了，但买点垃圾，是亏钱的第二大原因。

### 入场原则

**绝不追高。只做"确认后的回踩"。**

### 模型1：EMA回踩（最优先）

```
入场条件：
  1. 趋势向上（MA5 > MA10 > MA20）
  2. 价格回踩 20EMA（±3%以内）
  3. 成交量 < 20日均量 60%
  4. 出现 PA 反转 K 线

入场点：锤子线低点下方 1% 或 Engulfing 收盘价
止损点：锤子线低点 或 平台低点（取较低者）
止损类型：结构止损（必须说明）
```

### 模型2：平台突破回踩

```
入场条件：
  1. 放量突破平台（成交量 > 1.5倍 20日均量）
  2. 回踩平台（不跌回平台内部）
  3. 回踩缩量
  4. 再次放量阳线确认

入场点：平台高点上方 1%
止损点：平台下沿下方 1%
止损类型：结构止损
```

### 止损后重新进场条件

| 情况 | 是否可以重新进场 |
|------|----------------|
| 止损后 3 日内重新放量突破原止损位 | 可以，但需重新过五层 |
| 止损后跌破更低价 | 不可以 |

## 第五层：风险收益过滤

> 不是"能不能涨"，而是"值不值得赌"。

### 盈亏比要求

```
盈亏比 = 潜在涨幅 / 潜在跌幅
        = (第一目标 - 入场价) / (入场价 - 止损价)
```

| 盈亏比 | 操作 |
|--------|------|
| ≥ 2.5:1 | 正常仓位（15%） |
| 2.0~2.5:1 | 半仓（7.5%） |
| < 2.0:1 | 直接放弃 |

### IV 锚定 5 日价格区间

**用隐含波动率（IV）计算 5 日价格区间（70% 概率）：**

```python
import math

def calc_5day_price_range(price, iv_annual):
    """
    price: 当前股价
    iv_annual: 年化隐含波动率（0.40 = 40%）
    返回: (70%低价, 70%高价)
    """
    daily_vol = iv_annual / math.sqrt(252)
    # 1.04σ ≈ 70% 概率
    band = price * 1.04 * daily_vol * math.sqrt(5)
    return (price - band, price + band)

# 示例：股价 $100，IV = 40%
# low_70, high_70 = calc_5day_price_range(100, 0.40)
# → ($94.37, $105.63)  约68-70%概率落在区间内
```

### 止损规则

**必须说明止损类型：**

| 止损类型 | 说明 | 适用场景 |
|---------|------|---------|
| **结构止损** | 跌破关键支撑位（前低/平台/筹码区） | 趋势回踩、突破 |
| **指标止损** | 指标发出反向信号（MACD死叉） | 动量系统 |
| **波动止损** | 基于 ATR（如 2×ATR） | 高波动环境 |

### 止盈规则

| 目标 | 操作 |
|------|------|
| 盈亏比 1:1 时 | 减仓 1/3（收回本金） |
| 盈亏比 2:1 时 | 再减仓 1/3 |
| 之后 | 用 MA20 移动止损 |

## 第六层：综合技术分析（5维度动态加权）

> 15+ 个工具 → 归并为 5 个真正独立的维度
> 减少确认偏误，比平权投票更有统计意义

### 5 个独立维度

| 维度 | 包含工具 | 权重范围 |
|------|---------|---------|
| 趋势维度 | 道氏理论、Wyckoff、波浪（简化） | 0~25% |
| 动量维度 | RSI、TD序列、MACD柱状图 | 0~25% |
| 量价维度 | VSA、机构资金、筹码分布 | 0~25% |
| 结构维度 | 形态学、PA信号、斐波那契 | 0~25% |
| 情绪维度 | IV Rank、Put/Call Ratio、VIX | 0~25% |

### 维度权重分配规则

**趋势市（市场状态=强趋势上行）：**
```
趋势维度:   30%（权重最高）
动量维度:   10%（RSI可持续超买，权重低）
量价维度:   25%
结构维度:   20%
情绪维度:   15%（IV辅助）
```

**震荡市（市场状态=震荡区间）：**
```
趋势维度:    0%（禁止用趋势指标）
动量维度:   30%（RSI/TD权重最高）
量价维度:   15%
结构维度:   30%（形态/斐波权重最高）
情绪维度:   25%（IV/Ratio权重最高）
```

**高波动破位：**
```
趋势维度:   10%
动量维度:   10%
量价维度:   30%（VSA最重要）
结构维度:    0%（禁止形态分析）
情绪维度:   50%（IV/GEX权重最高）
```

### 各维度内部评分

**每个维度的最终得分取内部工具的加权平均：**

```
维度得分 = Σ(工具得分 × 工具权重) / Σ工具权重
工具得分: +2（强烈确认）/ +1 / 0 / -1 / -2（强烈否定）
```

### 置信度评估

| 得分范围 | 含义 |
|---------|------|
| ≥ +85（满分+100） | 极高——各维度高度一致 |
| +70 ~ +84 | 高——大部分维度一致 |
| +55 ~ +69 | 一般——不同维度结论分散 |
| < +55 | 放弃——无明确方向 |

## 第七层：期权链深度分析

### 7.1 数据获取

```python
# Yahoo Finance 期权链
options_url = f"https://finance.yahoo.com/quote/{ticker}/options"
# 提取：行权价 / OI / Vol / IV / PCR
```

### 7.2 分析维度

| 分析项 | 计算方式 | 看多信号 | 看空信号 |
|--------|---------|---------|---------|
| **Max Pain** | 到期让买方亏损最大的价格 | 当前价 < Max Pain | 当前价 > Max Pain |
| **GEX** | 期权市场 Gamma 总和 | 正 GEX = 波动被压制 | 负 GEX = 波动放大 |
| **DEX** | Delta 总暴露 | 正 DEX = 机构偏多 | 负 DEX = 机构偏空 |
| **IV Rank** | IV 在历史中的分位 | < 30%（期权便宜） | > 60%（期权昂贵） |
| **Put Wall** | 最大 Put OI 集中区 | 形成支撑 | 跌破则加速 |
| **Call Wall** | 最大 Call OI 集中区 | 形成压力 | 突破则加速 |
| **PCR** | Put/Call OI 比 | < 0.7（多头控盘） | > 1.0（空头主导） |
| **到期密度** | 近期大量合约到期 | — | 容易产生 Pin 效应 |

### 7.3 期权策略选择

| 条件 | 推荐策略 |
|------|---------|
| 看多 + IV Rank < 30% | 买入 Call（低成本） |
| 强烈看多 + IV 低 | 牛市 Call Debit Spread |
| 看多 + IV Rank > 60% | 买 Call + 卖更高 Call（收权利金降成本） |
| 已有持仓防风险 | Covered Call（增强收益） |
| 想低吸股票 | Cash Secured Put |

### 禁止操作

- 裸买 OTM 彩票期权
- 0DTE（极度高风险）
- 赌财报（IV crush 陷阱）

### 采用条件

必须同时满足：
1. 技术分析置信度 ≥ 高
2. 趋势概率上涨 ≥ 60%
3. IV Rank ≤ 40%

### 输出格式

```
【期权链分析】
Max Pain: $XXX（当前价 vs MP偏离：+X%）
GEX: +XX / -XX（正=压制波动 / 负=波动放大）
IV Rank: XX%（<30%=便宜 / >60%=贵）
PCR OI: X.XX（<0.7=多头 / >1.0=空头）
Put Wall: $XXX（支撑区）
Call Wall: $XXX（压力区）
近期到期: YES/NO（影响Pin效应）
机构情绪: 多头 / 中性 / 空头
期权策略: Call Debit Spread / 观望 / 不适用
```
