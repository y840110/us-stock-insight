# 短线博弈框架（高胜率专用）- 短线账户

> 版本：v1.1（2026-05-09 更新）
> 适用账户：短线账户（总资金 20%）
> 核心理念：**少而精**，不凑机会，分数不够就空仓

---

## 核心原则（四条铁律）

```
短线第一原则：止损到了就走，绝不留恋
短线第二原则：每笔亏损 ≤ 短线账户的 2%
短线第三原则：分数 < 3 分 → 跳过，不凑机会
短线第四原则：账号分开，盈亏独立计算，不补仓
```

---

## 与长线框架的隔离规则

| 维度 | 长线（原框架）| 短线（新框架）|
|------|-------------|-------------|
| 账户 | 长线账户（80%资金）| 短线账户（20%资金）|
| 目标 | 吃大趋势，高赔率 | 吃日内波动，高胜率 |
| 指标数量 | 15+ 复杂指标 | **5 分制评分** |
| 决策方式 | 深度分析 | 分数触发，不主观 |
| 持仓周期 | 数周~数月 | 数分钟~数天 |
| 操作频率 | 1个月 2~5 次 | 每周 3~10 次 |
| 胜率要求 | 40%+（靠赔率）| 55%+（靠胜率）|

**两套持仓绝对不互相影响决策。**

## 5 分制入场评分（核心工具）

> 把所有指标压缩成 5 分，只要 < 3 分就跳过

| 评分维度 | 2 分 | 1 分 | 0 分 |
|---------|------|------|------|
| **趋势** | EMA 多头排列，方向明确 | EMA 纠缠，无方向 | 逆势 |
| **结构** | 回踩关键支撑/压力位 | 接近支撑/压力，无明确信号 | 破位 |
| **信号** | 清晰的 PA 信号（锤子/吞没）| 模糊信号 | 无信号 |
| **仓位/流动性** | 成交量确认 | 成交量平淡 | 缩量/无量 |
| **风险回报** | 盈亏比 ≥ 2:1 | 盈亏比 1.5~2:1 | 盈亏比 < 1.5:1 |

### 评分规则

```
总分 = 趋势(2) + 结构(2) + 信号(2) + 量(2) + 风险回报(2) = 最高 10 分

≥ 6 分：允许入场（正常仓位）
3~5 分：观察，不操作
< 3 分：跳过，不凑机会
```

## 三种短线操作模型

### 模型A：EMA 回踩顺势（最优先）

```
适用：趋势明确的 ETF（SPY / QQQ）
条件：
  1. EMA5 > EMA20（多头排列）
  2. 价格回踩 EMA20
  3. 缩量
  4. 锤子线或吞没确认

入场：回踩 EMA20 位置
止损：EMA20 下方 0.5%
止盈：前高附近（1:1）
持仓：数分钟 ~ 数小时
```

### 模型B：开盘 30 分钟突破（ORB）

```
适用：活跃 ETF 和大型股
条件：
  1. 开盘 30 分钟内，成交量 > 均量 2 倍
  2. 突破开盘区间高点 / 低点
  3. 有明确方向

入场：突破确认后追入
止损：区间高低点外 0.5%
止盈：当日高低点附近
持仓：30 分钟 ~ 3 小时
```

### 模型C：支撑位企稳

```
适用：回踩支撑的强势股
条件：
  1. 价格回踩关键支撑（前低 / 整数关口）
  2. 缩量（机构没出货）
  3. PA 反转信号

入场：PA 确认后
止损：支撑位下方 0.5%
止盈：前高（1:1）
持仓：数分钟 ~ 隔夜
```

## 止损规则

### 每笔止损上限：短线账户的 2%

```
最大止损金额 = 短线账户总额 × 2%
仓位 = 最大止损金额 ÷（入场价 - 止损价）
```

### 止损执行

```
1. 到了止损位，立即市价平仓，不犹豫
2. 止损后不要立刻反手
3. 连续止损 2 次 → 当天停止交易
```

---

## 止盈规则

```
1:1 后：
  → 立即止盈，不留恋
  → 或移动止损到成本价

移动止损：价格每朝有利方向移动 0.5%，止损上移 0.5%
```

---

## 交易时间规则

| 时段 | 操作 | 原因 |
|------|------|------|
| 09:30 - 10:00 | 只做模型B（ORB开盘突破）| 流动性最佳 |
| 10:00 - 15:00 | 三种模型均可 | 趋势形成 |
| 15:00 - 16:00 | 只做模型A/C | 减少隔夜风险 |
| 收盘前 30 分钟 | 禁止开新仓 | 隔夜风险不可控 |

---

## 每日风险管理

```
每天最多亏损：短线账户的 5%
超过 5% → 当天停止交易
超过 10% → 暂停 1 周

同时持仓上限：最多 3 只
单只最大仓位：短线账户的 5%
单笔上限：短线账户的 10%
```

## 复盘日志（整个系统最重要的部分）

> 短线的进化完全依赖数据积累
> 建议用 Excel 或 Notion 维护，至少记录 30 笔后再调整参数

### 每日复盘格式

```
日期 | ticker | 模型 | 入场价 | 止损价 | 入场时间 | 出场时间 | 结果盈亏 | 分数 | 复盘原因
```

### 每周复盘问题

```
1. 本周胜率是多少？
2. 哪类模型胜率最高？
3. 分数 < 3 时是否正确跳过了？
4. 连续亏损的原因是什么？
5. 下周改进什么？
```

### 30 笔后调整规则

```
在积累 30 笔记录之前：
  → 不要修改任何参数
  → 不要凭感觉调整策略
  → 等待数据说话

30 笔后：
  → 根据真实数据调整评分权重
  → 根据胜率调整模型优先级
  → 根据平均持仓时间调整止盈目标
```

## 低胜率的短线习惯（必须禁止）

- 亏损后不甘心，反手操作
- 没有任何信号，凭感觉下单
- 追涨杀跌
- 重仓博一把
- 亏损后不平仓，等反弹（短线变长线）
- 在非交易时间操作
- **分数 < 3 硬凑机会**
