## 二、旧框架问题诊断

### 2.1 原架构（三层叠加，过度严格）

```
个股 → [CRO 七层过滤] → [SETUPS A/B/C] → [ML 二次确认] → 操作
```

**问题**：
- SETUPS 设计于震荡/熊市（均值回归），在 2024-2026 趋势牛市中完全不触发
- ML P_up>65% 阈值在牛市中整体偏低，导致 G6/G7 信号归零
- CRO 七层是"否决机制"而非"战略层"，导致机会大量流失

### 2.2 各组件评估

| 组件 | 回测表现 | 评估 | 角色调整 |
|------|---------|------|---------|
| **CRO 七层** | G1: 3,118笔/50%/夏普0.21 | ⚠️ 有效但粗糙 | 从"否决过滤器" → **"战略层：仓位管理器"** |
| **SETUPS A/B** | G2: 85笔/54.1%/+$2,417 | ✅ 有效 | 从"核心策略" → **"辅助参考：入场参考"** |
| **ML (P_up)** | G3: 84.3%胜率/因子14.39 | ✅ 极其有效 | **升级为"核心决策层"** |
| **ML (E[R])** | 未单独测试 | 待验证 | 作为 E[R]>1.5 二次确认 |

## 三、新架构设计

### 3.1 核心思想

> **"ML 为主，CRO 为辅，SETUPS 为参考"**

- ML P_up 是最准确的预测因子，作为入场核心决策
- CRO 用于决定**战略仓位**（进攻/防守），不是否决具体个股
- SETUPS 降级为辅助工具，提供精确入场点参考

### 3.2 新三层架构

```
输入股票
  │
  ▼
┌─────────────────────────────┐
│  第一层：CRO 战略层         │
│  （判断市场状态 → 决定仓位）   │
│  → 超强牛市 / 一般牛市 / 震荡 │
│  → 走弱 / 大跌              │
│  → 决定：风险敞口比例        │
└────────────┬──────────────┘
              │
              ▼
┌─────────────────────────────┐
│  第二层：ML 决策层          │
│  （P_up + E[R] 联合判断）    │
│  → P_up > 55%（牛市调低阈值）│
│  → E[R] > 1.0              │
│  → 决策：LONG / WATCH / 放弃│
└────────────┬──────────────┘
              │
              ▼
┌─────────────────────────────┐
│  第三层：SETUPS 参考层       │
│  （提供精确入场点参考）       │
│  → 策略A/B 触发 → 记录但不 │
│    作为否决条件              │
│  → 作为入场时机优化          │
└─────────────────────────────┘
```

### 3.3 关键变化

| 变化项 | 旧方案 | 新方案 |
|--------|--------|--------|
| ML 阈值 | P_up > 65% | P_up > **55%**（牛市）/ 60%（震荡）/ 50%（走弱）|
| CRO 角色 | 否决过滤器 | 战略仓位管理器 |
| SETUPS 角色 | 核心入场策略 | 辅助参考 |
| E[R] 使用 | 未明确使用 | E[R] > 1.0 作为第二确认条件 |
| 叠加逻辑 | 必须全部通过 | ML 通过即可以入场，CRO 决定仓位大小 |

## 四、CRO 战略层重构（市场状态机）

### 4.1 五级市场状态

源自 React 框架，融入 CRO 框架：

| 状态 | 评分区间 | 信号 | 仓位 | 说明 |
|------|---------|------|------|------|
| 🚀 超强牛市 | ≥ +8 | **全力进攻** | 1.5%风险敞口 | 跑赢大盘25%+的龙头 |
| 📈 一般牛市 | +4 ~ +7 | **稳健做多** | 1.0%风险敞口 | 跑赢10%+的标的 |
| ↔️ 震荡市场 | -3 ~ +3 | **高抛低吸** | 0.75%风险敞口 | 快进快出 |
| ⬇️ 市场走弱 | -4 ~ -7 | **极度谨慎** | 0.5%风险敞口 | 持有现金/防御ETF |
| 🔴 市场大跌 | ≤ -8 | **保存本金** | ≤0.5%反向ETF | 现金为王 |

### 4.2 市场评分规则（6项指标）

与 React 组件一致：

| 指标 | +2 分 | +1 分 | 0 分 | -1 分 | -2 分 |
|------|-------|-------|------|-------|-------|
| SPY vs MA20 | >+7% | +2%~+7% | -2%~+2% | -7%~-2% | <-7% |
| SPY vs MA50 | >+10% | +3%~+10% | -3%~+3% | -10%~-3% | <-10% |
| VIX | <13 | 13~18 | 18~24 | 24~32 | >32 |
| ADX | 多头>25 | 多头<25 | ADX<18 | 空头<25 | 空头>25 |
| 站上MA50比例 | >75% | 60%~75% | 45%~60% | 30%~45% | <30% |
| 新高/新低比 | >5× | 2×~5× | 0.5×~2× | 0.2×~0.5× | <0.2× |

**激活条件**：至少填写 4 项

### 4.3 各状态入场策略（精简版）

#### 🚀 超强牛市（评分 ≥+8）
- **首选**：浅回调做多（回踩MA10 ±1%，量缩≤0.75×，RSI 40-60）
- **次选**：高位箱体突破（整理3-8根K线，ATR收缩≤0.70×，放量确认）
- **止损**：MA10下方0.2×ATR
- **目标**：≥2.2:1
- **禁止**：RS<1.25的滞涨股

#### 📈 一般牛市（评分 +4~+7）
- **首选**：MA10-MA20区间回踩（回调5-12%，RSI 35-55）
- **次选**：量价突破（突破15日高点，量≥2×，RSI 45-68）
- **止损**：MA20下方0.3×ATR
- **目标**：≥2.0:1

#### ↔️ 震荡市场（评分 -3~+3）
- **首选**：支撑位低买（RSI<38，量缩，出现下影线）
- **次选**：压力位高卖（RSI>62，量增阴线）
- **持仓**：不超过5天，快进快出

#### ⬇️ 市场走弱（评分 -4~-7）
- **首选**：持有现金（≥75%）
- **唯一机会**：RS≥1.30的超强个股，RSI<40，回踩MA20
- **止损**：1.0×ATR（更紧）
- **目标**：1.5:1，降低目标

#### 🔴 市场大跌（评分 ≤-8）
- **唯一操作**：反向ETF（SH/PSQ），持仓≤3天
- **禁止**：抄底个股、加仓、任何中线决策

## 五、ML 决策层重构

### 5.1 动态阈值（按市场状态）

| 市场状态 | P_up 阈值 | E[R] 阈值 | 说明 |
|---------|-----------|-----------|------|
| 🚀 超强牛市 | > 55% | > 1.0 | 降低门槛，抓住更多机会 |
| 📈 一般牛市 | > 55% | > 1.0 | 同上 |
| ↔️ 震荡市场 | > 58% | > 1.2 | 适当提高，震荡市假信号多 |
| ⬇️ 市场走弱 | > 60% | > 1.5 | 严格筛选，只做高置信 |
| 🔴 市场大跌 | > 65% | > 1.5 | 最严格，或直接不做 |

### 5.2 ML 决策信号

| 信号 | 条件 | 操作 |
|------|------|------|
| **LONG** | P_up > 阈值 AND E[R] > 阈值 | 正常仓位入场 |
| **WATCH** | P_up > 阈值-5% OR E[R] > 阈值-0.3 | 半仓试探 |
| **NEUTRAL** | P_up ≤ 阈值-5% OR E[R] ≤ 阈值-0.3 | 放弃，等待 |
| **ABANDON** | CRO 判定为走弱/大跌 | 一票否决，完全不做 |

### 5.3 ML 校准验证（下次回测任务）

每次使用 ML 信号时，统计：
- P_up 55%~60% 的标的，实际上涨比例是否接近 57%？
- E[R] 1.0~1.5 的标的，实际平均R是否接近 1.25？

**如果偏差 > 15%，需要重训练模型。**

## 六、SETUPS 辅助参考层

### 6.1 角色调整

| 旧角色 | 新角色 |
|--------|--------|
| 核心入场策略（必须通过） | 辅助参考（提供精确入场点） |
| A/B/C 全部要求通过 | 仅作为 CRO 状态下的入场优化 |
| 否决条件 | 不否决，只加分 |

### 6.2 SETUPS 使用方式

**在超强牛市/一般牛市状态下**：
- 出现策略A信号 → 提示"超跌反弹机会，关注"
- 出现策略B信号 → 提示"量价突破机会，关注"
- **不要求必须满足 SETUPS 才能入场**
- **ML 信号通过即可入场，SETUPS 只作为精确点位参考**

**在震荡市场状态下**：
- 策略A（超跌反弹）优先级提升
- 策略B（量价突破）作为反向信号（突破可能是假信号）

### 6.3 SETUPS 新增：趋势市专用策略D

回测发现 SETUPS 在牛市失效，是因为 A/B 都是均值回归策略。补充趋势跟随策略：

**策略D：趋势回踩（Trend Pullback）— 牛市专用**

| 条件 | 阈值 |
|------|------|
| 市场状态 | 超强牛市 或 一般牛市 |
| 价格 vs MA20 | 在MA20上方，偏离≤+12% |
| RSI(14) | 40~60（健康回调区间）|
| 今日量 | ≤ 0.80× 20日均量（缩量回踩）|
| 下影线比例 | ≥ 35%（拒绝信号）|
| SPY 状态 | 非大跌日（评分>-4）|

```
入场：信号K线次日，突破信号日高点
止损：信号日最低价 - 0.3×ATR
目标：2.0:1
```
