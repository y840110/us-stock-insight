# VWAP 反弹完整 SOP

> 版本：v1.0 | 日期：2026-05-09
> 适用场景：价格回踩 VWAP 支撑/压力 | 标的：ETF / 大型股 / 强势股
> 模型：短线博弈框架 - 模型A / 模型C

---

## VWAP 核心定义

**VWAP = Volume Weighted Average Price（成交量加权平均价）**

当日机构成本区，价格在 VWAP 上方 = 机构在买入；下方 = 机构在卖出。

---

## VWAP 关键逻辑

```
价格在 VWAP 上方 + 回踩 VWAP = 买入机会（机构可能继续买）
价格在 VWAP 下方 + 反弹 VWAP = 卖出机会（机构可能继续卖）

VWAP 相当于当日的"价值线"
  → 价格低于 VWAP = 便宜
  → 价格高于 VWAP = 贵
```

---

## VWAP 使用前提

```
必须满足：
  1. 标的在 MA20 上方（多头市场）
  2. VWAP 倾斜向上（上升趋势）
  3. 成交量 > 均量（机构参与）

禁止使用：
  1. 标的在 MA20 下方（下跌趋势）
  2. VWAP 走平（震荡市）
  3. 缩量（无机构参与）
```

## 模型A：EMA回踩VWAP（顺势多）

### 适用场景
上升趋势中的回踩买点，专门做顺势多。

### 信号确认（5步）

```
Step 1：趋势确认
  → EMA5 > EMA20 > EMA60（多头排列）
  → 标的价格在 MA20 上方
  → 这是前提，不满足直接跳过

Step 2：VWAP 回踩确认
  → 价格回踩 VWAP（±1% 以内）
  → 在 VWAP 附近出现缩量（机构没出货）
  → 最低价不能跌破 VWAP 超过 1%

Step 3：K线信号确认
  → 出现以下任一 PA 信号：
    - 锤子线（Hammer）
    - 吞没阳线（Bullish Engulfing）
    - Morning Star
  → 不满足继续等待

Step 4：量能确认
  → 回调时缩量（< 20 日均量 60%）
  → 反弹时放量（> 均量）
  → 这步是加分项，不是必须

Step 5：大盘确认
  → SPY 在 MA20 上方
  → SPY 不是在急跌中
```

### 交易参数

```
入场：VWAP 位置（$XXX）
止损：VWAP 下方 0.5%（$XXX）
目标1：前高或日内高点（1:1）
目标2：前高 × 1.5（1.5:1）
持仓：数分钟 ~ 数小时（收盘前平仓）
```

### 仓位计算

```
最大止损 = 短线账户 × 2%
止损幅度 = |入场价 - 止损价| / 入场价
仓位 = 最大止损 / 止损幅度
```

## 模型C：支撑位VWAP反弹（逆势抄底）

### 适用场景
价格急跌到 VWAP 支撑，出现反弹信号。

### 信号确认（5步）

```
Step 1：超跌确认
  → 价格快速下跌 > 1%
  → 价格在 VWAP 下方 > 1%
  → RSI < 40（短线超卖）

Step 2：支撑确认
  → VWAP 作为支撑位
  → 或者前低作为支撑
  → 价格在这两个位置附近

Step 3：企稳信号
  → 出现以下任一 PA 信号：
    - 锤子线（Hammer）
    - 吞没阳线
    - 长下影线
  → 阳线收盘在 VWAP 上方更好

Step 4：缩量确认
  → 急跌时放量 = 机构出货 → 放弃
  → 急跌时缩量 = 可能是震仓 → 关注
  → 反弹时放量确认

Step 5：大盘确认
  → SPY 不是在急跌中
  → 最好 SPY 在 MA20 附近企稳
```

### 交易参数

```
入场：PA 信号确认后（$XXX）
止损：VWAP 下方 0.5% 或 前低下方 0.5%（取较近者）
目标：VWAP 位置（如果之前在 VWAP 上方）
     或者 前高（如果反弹到前高附近）
持仓：数分钟 ~ 隔夜（收盘前决定是否留）
```

## 每日 VWAP 复盘要点

```
1. 价格全天在 VWAP 上方还是下方？
2. 每次回踩 VWAP 是否出现买入信号？
3. 是否有效突破 VWAP？（突破后站稳）
4. 大盘 VWAP 与个股 VWAP 的关系？
5. 哪类信号胜率最高？
```

## VWAP 禁止清单

| 情况 | 原因 |
|------|------|
| 标的在 MA20 下方 | 下跌趋势，顺势不做逆势多 |
| VWAP 走平 | 震荡市，无方向 |
| 价格跌破 VWAP > 1% | 机构在卖出，不是买入机会 |
| RSI > 70 | 超买，回调风险大 |
| 急跌时放量 | 机构出货，不能接飞刀 |
| 大盘急跌中 | 系统性风险，禁止抄底 |

## 三种模型综合对比

| 维度 | 模型A（EMA+VWAP）| 模型C（VWAP支撑）| 模型B（ORB）|
|------|-----------------|----------------|------------|
| 核心逻辑 | 顺势回踩 | 逆势抄底 | 突破追入 |
| 市场环境 | 上升趋势 | 急跌反弹 | 单边突破 |
| 止损位置 | VWAP 下方 0.5% | 前低下方 0.5% | 区间外 0.5% |
| 目标 | 前高（1:1）| VWAP/前高 | 区间宽度 |
| 胜率最高场景 | 上升趋势中的回踩 | 超跌后的反弹 | 趋势明确的突破 |
| 最大风险 | 假突破 | 接飞刀 | 假突破 |

## VWAP + 5分制评分对应

| 评分维度 | 对应 VWAP 信号 |
|---------|---------------|
| 趋势（2分）| EMA多头排列 + 在MA20上方 = 2分 |
| 结构（2分）| 价格回踩VWAP = 2分；接近VWAP = 1分 |
| 信号（2分）| PA锤子/吞没 = 2分；模糊 = 1分；无 = 0分 |
| 量能（2分）| 缩量回调 + 放量反弹 = 2分；平淡 = 1分 |
| 风险回报（2分）| 盈亏比 ≥ 2:1 = 2分；1.5~2 = 1分 |

```
总分 ≥ 6 分 → 操作
总分 3~5 分 → 观察
总分 < 3 分 → 跳过
```
