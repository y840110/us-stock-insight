# 高胜率短线 / 日内交易框架（v2）

> 版本：v2.0 | 日期：2026-05-09
> 适用账户：短线账户（20%资金）
> 核心理念：赌"流动性失衡"，不是赌"趋势"
> 与长线框架的根本区别：波段赌趋势，日内赌情绪失衡

---

## 核心理念：两套系统必须完全分离

| 账户 | 类型 | 目标 | 思维 |
|------|------|------|------|
| A账户（长线）| 中线波段 | 稳定大盈利 | 赌"趋势" |
| B账户（短线）| 短线/日内 | 提高资金效率 | 赌"情绪失衡" |

**两套系统必须完全分离，否则逻辑冲突、仓位混乱、节奏失控。**

---

## 一、短线系统的核心逻辑

### 波段看什么
- 周线
- 趋势
- 基本面
- 机构资金

### 日内看什么
- **流动性**
- **情绪**
- **波动率**
- **订单流**
- Level 2
- **VWAP**
- **Gamma**

> 绝对不能用波段思维做日内，否则必死。

---

## 二、适合的风格：「低频日内趋势交易」

又称 **Intraday Swing**

| 特征 | 内容 |
|------|------|
| 持仓时间 | 10分钟 ～ 数小时 |
| 交易频率 | 每天 0~3 笔 |
| 风格 | 等确定性 |
| 核心 | 趋势 + VWAP |
| 风险 | 可控 |
| 胜率 | 明显高于乱打 |

### 禁止的行为
- 高频 scalp
- 1分钟乱打
- 赌消息
- 赌财报
- 逆势抄底
- 满仓隔夜

---

## 三、日内只做「机构推动的强趋势」

- 不要做震荡
- 不要预测顶部
- 不要抄底

---

## 四、五层结构

### 第一层：市场环境过滤（最重要）

日内第一原则：大部分股票跟指数。

**开盘前必看：**

| 指标 | 作用 |
|------|------|
| SPY | 市场方向 |
| QQQ | 科技情绪 |
| VIX | 风险水平 |
| TICK | 市场广度 |
| ADD | 多空强弱 |
| NVDA / TSLA | 情绪龙头 |

**只做指数方向明确的时候。**

### 禁止交易环境

| 情况 | 原因 |
|------|------|
| 开盘前30分钟极混乱 | 容易扫损 |
| FOMC / CPI | 假动作极多 |
| 午间低量 | 随机波动 |
| 指数无趋势 | 个股容易假突破 |

---

### 第二层：只做市场最强股票

**Relative Volume（RVOL）爆发是日内生命线。**

| 条件 | 标准 |
|------|------|
| RVOL | > 2 |
| 当天成交量 | 显著放大 |
| 行业联动 | 强 |
| 有新闻/催化 | 最佳 |

> 日内：没有量 = 没有交易。

---

### 第三层：只做三种形态（系统灵魂）

#### A类：开盘趋势延续（最稳）

```
条件：
  - Gap Up
  - 放量
  - 强于指数
  - 开盘不回补缺口
  - 站稳 VWAP

做法：等第一次回踩 VWAP
  → 缩量
  → 拒绝跌破
  → 再放量拉升
  → 才进
```

#### B类：VWAP趋势回踩（核心，最稳定）

```
条件：
  - 明显趋势
  - 始终在 VWAP 上方
  - 回踩 VWAP 不破
  - 成交量缩小

这是日内最稳定的模型。
```

#### C类：午后趋势突破

```
条件：
  - 上午横盘
  - 波动率压缩
  - 午后放量突破

这是日内第二波机构资金。
```

## 六、最重要核心：VWAP（灵魂）

**日内交易本质：是机构围绕 VWAP 博弈。**

| 位置 | 含义 |
|------|------|
| VWAP 上方 | 多头控制 |
| VWAP 下方 | 空头控制 |

**原则：只做多头在 VWAP 上方 / 空头在 VWAP 下方，不要逆 VWAP。**

---

## 七、入场模型

### 模型1：VWAP 回踩

```
条件：
  - 趋势明确
  - 回踩 VWAP
  - 缩量
  - 出现大单买入

进场。
```

### 模型2：ORB（开盘区间突破）

```
条件：
  - 前30分钟高点突破
  - 放量
  - SPY 同步

这是经典模型。
```

### 模型3：High Tight Flag

```
条件：
  - 急拉
  - 缩量横盘
  - 再突破

这是龙头常见结构。
```

---

## 八、止损原则

**小亏必须极快。日内最忌："再等等"。**

| 交易类型 | 止损位置 |
|---------|---------|
| VWAP 交易 | VWAP 失守 |
| ORB | 跌回区间 |
| Flag | 跌破旗形 |

## 九、仓位管理

| 情况 | 仓位 |
|------|------|
| 普通机会 | 10~15% |
| 极佳机会 | 20~25% |
| 不确定 | **不做** |

---

## 十、最重要规则：「不交易」也是交易

真正高水平的日内：
- 一天只做 1 笔
- 甚至 0 笔
- 等最漂亮结构

而不是：
- 一天乱打 20 次

**大量时间：等、看、不交易。只有流动性 + 趋势 + 量能同时出现，才出手。**

---

## 十一、收盘前原则

**大部分仓位不隔夜。**

除非同时满足：
- 市场极强
- 趋势明确
- 有巨大优势

---

## 十二、开盘前检查清单

```
□ SPY 方向明确？
□ QQQ 方向明确？
□ VIX < 25？
□ 今日无重大宏观数据？
□ 有 RVOL > 2 的标的？
□ 有新闻/催化？
□ 指数有趋势？
```

---

## 十三、与 v1.0 框架的关系

| 项目 | v1.0（选股框架）| v2.0（日内框架）|
|------|----------------|----------------|
| 持仓 | 数分钟~数天 | 10分钟~数小时 |
| 核心 | 5分制评分 | VWAP + 量能 |
| 指标 | 趋势/结构/信号/量/风险回报 | VWAP/9EMA/Volume/RVOL |
| 适用 | 盘中选股 | 日内择时 |
| 模型 | A/B/C（EMA回踩/ORB/支撑）| A/B/C（趋势延续/VWAP回踩/午后突破）|

**两个版本互补使用：**
- v1.0：盘中决定"做哪只"
- v2.0：盘中决定"什么时候进"

## 十四、最终规则速查

```
日内只做：
  ✅ VWAP 趋势
  ✅ ORB 突破
  ✅ Flag 延续
  ✅ 强势股（RVOL > 2）

日内禁止：
  ❌ 抄底
  ❌ 猜顶部
  ❌ 逆势
  ❌ 无量股票
  ❌ 重仓隔夜
  ❌ 高频乱打
```
