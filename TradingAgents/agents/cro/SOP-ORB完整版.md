# ORB 完整 SOP（开盘区间突破）

> 版本：v1.0 | 日期：2026-05-09
> 适用场景：开盘 30 分钟突破 | 标的：ETF / 大型股
> 模型：短线博弈框架 - 模型B

---

## ORB 核心定义

**ORB = Opening Range Breakout（开盘区间突破）**

开盘后前 30 分钟形成一个价格区间，突破这个区间后顺势交易。

---

## ORB 完整执行流程

### 第一步：开盘前准备（09:25 - 09:30）

```
任务：
  1. 打开 5 分钟图表
  2. 确认大盘（SPY / QQQ）方向
  3. 查看 VIX 是否 > 25（>25 禁止 ORB）
  4. 确认今日有重要宏观数据发布（有 → 跳过 ORB）

检查清单：
  [ ] SPY 开盘方向？
  [ ] VIX < 25？
  [ ] 无重大数据今日？
  [ ] 目标标的流动性充足？
```

---

### 第二步：确定开盘区间（09:30 - 10:00）

```
开盘后立即开始记录：

记录高点：开盘30分钟内最高价 → HIGH
记录低点：开盘30分钟内最低价 → LOW
区间宽度 = HIGH - LOW

⚠️ 区间宽度判断：
  宽度 < $0.50（ETF）：区间太窄，容易假突破 → 放弃
  宽度 > $5.00（个股）：区间太宽，止损过大 → 降低仓位
  合理宽度：$0.50 ~ $3.00（ETF）
```

---

### 第三步：等待突破确认（10:00 之后）

#### 做多突破（Buy Breakout）

```
条件（全部满足）：
  1. 价格向上突破 HIGH
  2. 突破时成交量 > 开盘区间均量 1.5 倍
  3. 突破在 10:00 之后（不在 09:30-10:00 内部）
  4. SPY 同时在 MA5 上方（顺势）

突破确认（必须看到）：
  - 价格已站稳在 HIGH 上方
  - 回调不低于 HIGH（否则是假突破）
  - 有放量阳线

❌ 放弃情况：
  - 开盘区间内反复震荡
  - 突破后迅速跌回（假突破）
  - 大盘弱（SPY 在 MA5 下方）
```

#### 做空突破（Sell Breakout）

```
条件（全部满足）：
  1. 价格向下突破 LOW
  2. 突破时成交量 > 开盘区间均量 1.5 倍
  3. 突破在 10:00 之后
  4. SPY 同时在 MA5 下方（顺势）

❌ 放弃情况：
  - 跌破后迅速涨回（假突破）
  - 大盘强（SPY 在 MA5 上方）
```

---

### 第四步：计算交易参数

```
入场价：突破确认后的回调低点（做多）/ 反弹高点（做空）
       或者直接市价追入（保守者用回调，激进者用市价）

止损价：
  做多：LOW 下方 0.5%（不破开盘区间低点）
  做空：HIGH 上方 0.5%

止盈目标：
  第一目标：入场价 + 区间宽度（1:1）
  第二目标：入场价 + 区间宽度 × 1.5

最大仓位：
  短线账户 10% × 风险比例

风险计算：
  止损幅度 = |入场价 - 止损价| / 入场价
  仓位 = 短线账户 × 2% / 止损幅度
  仓位 = min(计算仓位, 短线账户 × 10%)
```

---

### 第五步：盘中监控

```
入场后：
  1. 价格朝有利方向移动：
     → 每上涨 0.5%，止损上移 0.5%（移动止损）
     → 到达 1:1 后，止盈 1/3，剩余用移动止损
  
  2. 价格触及止损：
     → 立即市价平仓
     → 不犹豫，不等待反弹
     → 记录一笔亏损
  
  3. 假突破（突破后迅速跌回）：
     → 跌回区间内 → 立即止损
     → 这是 ORB 最常见的亏损模式
  
  4. 到达第一目标：
     → 减仓 1/3（收回本金）
     → 剩余仓位移动止损到成本价
     → 博第二目标
```

---

### 第六步：收盘前规则

```
15:30 之后：
  ❌ 禁止新开 ORB 仓位
  
  持仓处理：
    → 如果在盈利，持有到收盘
    → 如果在亏损，触及止损走，不留隔夜
  
  收盘前 5 分钟：
    → 有盈利的仓位可以主动止盈
    → 不用等到 16:00 市价平仓
```

## ORB 禁止清单

| 情况 | 原因 |
|------|------|
| VIX > 25 | 波动过大，假突破多 |
| 有重大宏观数据发布日 | 方向不确定 |
| 开盘区间太窄（< $0.50）| 假突破 |
| 大盘与方向相反 | 逆势风险 |
| 突破后迅速跌回 | 假突破 |
| 非交易时段 | 禁止开仓 |

## ORB 每日记录

```
日期 | 标的 | 方向 | 区间宽 | 入场价 | 止损价 | 出场价 | 盈亏 | 假突破? | 复盘
```

---

## ORB 常见错误

1. **在 09:30-10:00 内追突破**（时间未到，区间未确定）
2. **区间太窄时仍做 ORB**（假突破率高）
3. **假突破不止损**（等反弹 → 短线变长线）
4. **逆势 ORB**（SPY 跌时做多 ORB）
5. **数据日前一天做 ORB**（预期波动大）

## ORB vs 其他模型对比

| 维度 | ORB（模型B）| EMA回踩（模型A）| 支撑反弹（模型C）|
|------|-------------|----------------|----------------|
| 时间 | 10:00后最佳 | 10:00-15:00 | 10:00-15:00 |
| 方向确认 | 突破确认 | EMA回踩确认 | 支撑位确认 |
| 止损 | 区间外 0.5% | EMA下方 0.5% | 支撑下方 0.5% |
| 止盈 | 区间宽度 | 前高 | 前高 |
| 胜率最高场景 | 趋势明确的单边 | 回调中的顺势 | 震荡中的反弹 |
