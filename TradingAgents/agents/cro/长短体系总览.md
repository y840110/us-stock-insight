# 长短线双体系总览

> 版本：v1.0 | 日期：2026-05-09
> 核心理念：长线吃趋势，短线吃波动，两套体系互不干扰

---

## 核心原则：三个绝对分开

| 原则 | 说明 |
|------|------|
| **账号分开** | 长线账号 = 长线账户；短线账号 = 专门短线账户 |
| **仓位分开** | 长线仓位永远不动；短线仓位独立计算 |
| **不补仓** | 任何一边的亏损，都不能用另一边来救 |

---

## 长线体系（已有框架）

**框架文件：** `美股投资洞察分析/agents/cro/综合分析框架.md`

**核心理念：**
- 只在优势巨大时下注（1个月出手 2~5 次）
- 五层过滤 + 七层分析
- 盈亏比 ≥ 2.5:1
- 高置信度（≥ 85分）才操作

**适合标的：**
- 趋势明确的强势股
- 机构资金持续流入的板块
- 回调充分的龙头

**单笔仓位：** 总账户 15%（置信度极高时）
**止损类型：** 技术止损（结构失效止损）

---

## 短线体系（新建框架）

**框架文件：** `美股投资洞察分析/agents/cro/短线博弈框架.md`

**核心理念：**
- 专门捕捉日内 / 隔夜的流动性波动
- 严格止损（每笔亏损 ≤ 2%）
- 不留恋，止损到了就走
- 追求的是"高胜率"而不是"高赔率"

**适合标的：**
- 成交量活跃的 ETF（SPY / QQQ / TLT）
- 消息面驱动的日内行情
- 开盘30分钟的高流动性时段
- 趋势强烈的股票回调日内支撑位

**单笔仓位：** 短线账户 10%（每笔风险 ≤ 总短线账户 2%）

---

## 两套体系的根本区别

| 维度 | 长线 | 短线 |
|------|------|------|
| 目标 | 吃大趋势，高赔率 | 吃日内波动，高胜率 |
| 止损 | 结构止损（偏大） | 固定2%（偏小） |
| 持仓时间 | 数周~数月 | 数分钟~数天 |
| 操作频率 | 1个月2~5次 | 每周3~10次 |
| 胜率要求 | 40%+（靠赔率赚钱） | 55%+（靠胜率赚钱） |
| 分析工具 | 七层框架，复杂 | 简单信号，快速判断 |
| 仓位 | 15% 长线账户 | 10% 短线账户 |
| 加仓 | 不补仓 | 不补仓 |
| 允许亏损 | 可接受20~30%回撤 | 每笔≤2% |

## 账号管理

```
总账户（统一管理）
  ├── 长线账户（总资金 80%）
  │   ├── 独立持仓
  │   ├── 独立计算盈亏
  │   └── 止损：结构止损
  │
  └── 短线账户（总资金 20%）
      ├── 独立持仓
      ├── 独立计算盈亏
      └── 止损：固定2%每笔
```
