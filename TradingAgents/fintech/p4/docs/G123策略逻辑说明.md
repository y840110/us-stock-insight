# G1 / G2 / G3 策略逻辑详解

> 文档版本：2026-05-16
> 对应代码：`fintech/p4/g1_screener.py` / `g2_screener.py` / `g3_screener.py`

---

## 核心理念

三个策略各自**独立评估**同一只股票，互不干扰：
- **G1** — 趋势跟随（What：追涨顺势）
- **G2** — 低吸回踩（When：买在回调）
- **G3** — ML 概率预测（Model：数据驱动）

最终分层（L1/L2/L3/L4）由 `synthesize.py` 综合三个策略的评分结果，叠加板块因素后统一判定。

---

## G1 — 趋势跟随（Trend Following）

### 核心理念
> "趋势是你唯一的朋友。" — Jesse Livermore

在明确的趋势方向上持有头寸，直到趋势破坏。核心是** EMA 多头排列 + RSI 处于健康区间 + 动量正向**。

### 触发条件（牛市环境）

| 条件 | 说明 |
|------|------|
| `trend == 1` | EMA5 > EMA20 > EMA50（趋势分数 ≥12） |
| `RSI Zone ∈ {OPTIMAL, BULL_CONFIRM}` | RSI 在 45~75 之间，不是超买也不是超卖 |
| `mom20 > 0` | 20日动量为正，趋势正在朝上走 |

### RSI Zone 划分

| Zone | RSI 范围 | 说明 |
|------|----------|------|
| OVERBOUGHT | > 75 | 超买，拒绝追高 |
| BULL_CONFIRM | 65 ~ 75 | 偏高但仍在趋势中，可接受 |
| OPTIMAL | 45 ~ 65 | 理想入场区间 |
| PULLBACK | 30 ~ 45 | 回踩，暂不追涨 |
| OVERSOLD | < 30 | 超卖，等更低价格 |

### 评分公式

```
score = min(100, 50 + mom20×2 + (70-RSI)×0.5 + MACD_hist×5)
```

- `mom20×2`：动量越大分数越高
- `(70-RSI)×0.5`：RSI 越接近 70（强势区）分数越高
- `MACD_hist×5`：MACD 直方图为正且越大越好
- 下限 50，上限 100

### 分层结果

| Tier | 含义 |
|------|------|
| **L1** | 完美趋势信号，全部条件满足 |
| **L4** | 趋势不明（trend==0 或 熊市中 trend==-1 且 RSI<40） |

### 不同 Regime 下的行为

| Regime | G1 行为 |
|--------|---------|
| 超强牛市 / 一般牛市 | 趋势跟随，L1 追涨 |
| 震荡市 | RSI 超卖时抢反弹，L2 |
| 熊市 | 现金为王，仅超跌反弹可做 L2 |

## G2 — 低吸 / 回踩买入（Pullback Setup）

### 核心理念
> "买在恐慌，卖在狂热。" — George Soros

强势股不会直线上涨，总会有回踩。G2 在回踩发生时**趁低买入**，成本优于追涨。

### 触发条件（牛市环境）

**核心信号：**
| 条件 | 说明 |
|------|------|
| `trend == 1` | 股票仍是上升趋势 |
| `RSI Zone ∈ {PULLBACK, OVERSOLD}` | 正好在回调或超卖区间 |
| `dist_ema20 > -15%` | 距离 EMA20 不超过 -15%，不要太深 |

**评分公式（回踩版）：**
```
score = min(100, 40 + |RSI - 35| + dist_ema20×(-1))
```

- `|RSI-35|`：RSI 越低（即越超卖），分数越高
- `dist_ema20×(-1)`：越贴近 EMA20（dist 越接近 0），分数越高

**延伸信号（强势追涨）：**
当 RSI 已在 OPTIMAL/BULL_CONFIRM 区间，但 momentum 仍然很强时，也接受为 L2 追涨：
```
score = min(100, 30 + mom20×1.5)
```

### RSI Zone 在 G2 中的角色

G2 专门利用 G1 拒绝的 RSI 区间：

| RSI Zone | G1 态度 | G2 态度 |
|----------|---------|---------|
| OVERBOUGHT (>75) | 拒绝（NONE） | 拒绝 |
| BULL_CONFIRM (65~75) | 接受 L1 | 不接受（追高风险大） |
| OPTIMAL (45~65) | 接受 L1 | 不接受（已涨过） |
| PULLBACK (30~45) | 拒绝 | **核心信号** |
| OVERSOLD (<30) | 拒绝 | **深度回踩信号** |

两者形成完美互补——G1 买涨、G2 买跌。

### 分层结果

| Tier | 含义 |
|------|------|
| **L2** | 正常回踩低吸机会 |
| **L3** | 超卖但偏离过大（dist_ema20 ≤ -15%），降级观察 |

## G3 — ML 概率预测（Machine Learning）

### 核心理念
> 不是问"这只股票会不会涨"，而是问"在当前市场结构下，它涨的概率有多大"。

使用历史数据训练的机器学习模型，预测未来5日上涨概率（**P_up**）。

### 模型说明

| 项目 | 内容 |
|------|------|
| 模型类型 | sklearn GradientBoostingClassifier + RandomForest 集成 |
| 训练标签 | 5日后涨幅 >2% → up / 跌幅 >2% → down / 其他 → neutral |
| 特征输入 | 32个技术因子（RSI、动量、波动率、MA关系、成交量比等） |
| 模型文件 | `fintech/p4/ml/models/winrate_model.pkl` |

### 关键输入因子（来自 calc_all_factors）

```
close, return_1d/5d/10d/20d, ma5/10/20/50/200, ema5/10/20/50/200,
ma5_above_ma20, ma20_above_ma50, price_above_ma200,
atr14, atr20, atr14_pct, vol20_std, vol_ma20, vol_ratio,
mom5/10/20, bb_width, bb_pos, rsi14
```

### P_up 阈值（随 Regime 调整）

| Regime | P_up 阈值 | 说明 |
|--------|-----------|------|
| 超强牛市 / 一般牛市 | ≥ 0.45 | 环境好，低概率也可信 |
| 震荡市 | ≥ 0.45 | 阈值不变 |
| 熊市 | ≥ 0.55 | 环境差，需要更强信号 |

### 评分公式

```
score = P_up × 100
```

例：P_up = 0.52 → score = 52

### 输出结构

```python
{
    'P_up': 0.52,       # 上涨概率
    'P_down': 0.25,     # 下跌概率
    'P_neutral': 0.23,  # 震荡概率
    'signal': 'WATCH'   # LONG(>0.65) / WATCH(0.50~0.65) / NEUTRAL(<0.50)
}
```

## 综合分层（synthesize.py）

三个策略独立评估后，`synthesize.py` 执行最终综合评判。

### 权重分配（随 Regime 动态调整）

| Regime Score | G1 权重 | G2 权重 | G3 权重 |
|-------------|---------|---------|---------|
| ≥ 8（超强牛市） | **80%** | 10% | 10% |
| ≥ 6（一般牛市） | 60% | 20% | 20% |
| ≥ 4（震荡市） | 30% | **50%** | 20% |
| < 4（熊市） | 10% | 40% | **50%** |

### 综合评分

```
final_score = G1_score × G1_weight + G2_score × G2_weight + G3_score × G3_weight + sector_adjustment
```

**板块调节**：
- P3 热门板块（L1）：+10 分
- P3 冷门板块（L4）：-10 分，可能触发降 tier

### 最终 Tier 判定

| 最终 Tier | 条件 |
|-----------|------|
| **L1 强烈推荐** | final_score ≥ 75 **且** 通过 ≥ 2 个策略 |
| **L2 推荐** | final_score ≥ 60 **且** 通过 ≥ 1 个策略 |
| **L3 观察** | final_score ≥ 45 |
| **L4 回避** | final_score < 45 |

> 通过定义：G1 tier==L1 / G2 tier==L2 / G3 tier==L3

### 降 tier 规则

若板块为 P3 L4（极端弱势），即使分数够也可能降级：
- L1 → L3（板块太弱）
- L1 → L2（板块偏弱）

## 三策略对比速查

| 维度 | G1 趋势跟随 | G2 低吸回踩 | G3 ML 概率 |
|------|------------|------------|------------|
| **入场时机** | 涨势中追入 | 回踩后低吸 | 随时（看概率） |
| **RSI 偏好** | 45~75（健康区） | 30~45（偏低区） | 任意 |
| **核心指标** | EMA排列 + 动量 | RSI回踩 + 距EMA距离 | P_up 概率 |
| **最适 Regime** | 超强牛市 | 震荡/牛市回调 | 任意（阈值不同） |
| **输出 Tier** | L1 / L4 | L2 / L3 | L3 |
| **分数公式** | 50+mom×2+(70-RSI)×0.5 | 40+\|RSI-35\|+dist×(-1) | P_up×100 |
| **与 G1/G2 关系** | — | G1 的互补面 | 独立，可叠加 |

## 典型场景分析

### 场景1：强势趋势股（RSI 65~75）

```
G1: tier=L1 ✅  → score≈85（高分）
G2: tier=NONE（RSI 不在回踩区）→ score=0
G3: tier=L3（若 P_up≥0.45）→ score=P_up×100
→ 综合通过 G1+G3，final_score 高 → L1 强烈推荐
```

### 场景2：强势股回踩（RSI 35，趋势完好）

```
G1: tier=NONE（RSI 不在 OPTIMAL 区）→ score=0
G2: tier=L2 ✅  → score≈70
G3: tier=L3（若 P_up≥0.45）→ score=P_up×100
→ 综合通过 G2，final_score 中高 → L2 推荐
```

### 场景3：ML 信号强烈但趋势弱（P_up=0.62，trend=0）

```
G1: tier=L4（趋势不明）→ score=20
G2: tier=NONE（无明确回踩信号）
G3: tier=L3 ✅  → score=62
→ final_score ≈ 62×10%+20×80% ≈ 26（权重偏向熊市/震荡调整）
→ 板块调节后可能 L3 观察
```
