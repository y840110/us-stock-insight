# G4 专家策略蒸馏 — 技术方案

> 创建时间：2026-05-16
> 状态：方案阶段

---

## 一、核心思路

不是"模仿下单动作"，而是**蒸馏专家的决策框架**：
- 他们如何解读市场状态
- 哪些信号对他们最重要
- 他们的决策条件树

最终目标：用专家的思维框架辅助投资决策。

---

## 二、数据来源

| 来源 | 内容 | 难度 | 优先级 |
|------|------|------|--------|
| Twitter/X 分析帖 | 片段化决策理由，结构清晰 | ⭐ 极易 | P0 |
| YouTube（Warrior Trading, Rayner Teo） | 每日点评、策略讲解 | ⭐ 较易 | P1 |
| 视频课字幕（方方土等） | 结构化知识，已下载 | ⭐ 较易 | **P0（已有）** |
| Zoom录屏（真实学员复盘） | 决策过程 | ⭐⭐⭐ 需授权 | P2 |
| 付费课程字幕（SMB, Tai Tan） | 结构化知识 | ⭐⭐ 中等 | P1 |

## 三、技术 pipeline

```
视频/音频
    ↓
[Whisper 语音转文字]  ──→  文本片段 + 时间戳
    ↓
[对齐市场数据]  ──→  每个片段匹配：K线状态 + 技术指标 + 板块环境
    ↓
[LLM 提炼决策框架]  ──→  结构化信号标签
    ↓
[训练决策模型]  ──→  G4 推理引擎
```

## 四、信号标签体系

每个视频片段打标签：

```python
{
    "expert": "方方土",
    "segment": "这段内容的文字",
    "timestamp": "02:34",
    "market_regime": "Uptrend" | "Pullback" | "Breakout" | "Range",
    "action": "BUY" | "SELL" | "HOLD" | "WATCH",
    "key_signals": ["RSI divergence", "Volume spike", "News catalyst"],
    "entry_conditions": ["RSI < 40", "Above 20EMA"],
    "timeframe": "Intraday" | "Swing" | "Position",
    "confidence": 0.0~1.0,
}
```

## 五、G4 模型架构

```
输入层
├─ 视频片段 embedding（Whisper/文本 encoder）
├─ 市场状态向量（RSI, 趋势, 波动率, 板块热度, VIX）
└─ 历史上下文（过去5根K线的价格/成交量）
    ↓
决策 Transformer
├─ 专家决策条件树（if-then 规则提炼）
├─ 多专家 ensemble（不同专家有权重）
└─ Regime-aware 路由（牛市/熊市用不同决策分支）
    ↓
输出
├─ G4_tier: L1/L2/L3/L4/NONE
├─ G4_score: 0~100
├─ G4_reasons: [专家信号理由]
└─ expert_attribution: "来源: 具体理由"
```

## 六、实施路线图

### Phase 1：数据工程（2~3周）
- 构建 YouTube 爬虫，收集10+位知名交易员的视频
- Whisper 批量转写（每分钟约0.5元）
- 人工抽检 + 修正 5% 片段

### Phase 2：标注与对齐（2周）
- LLM 自动打标签（GPT-4o 解析专家语言，提炼信号）
- 自动对齐：时间戳 → 当日K线数据
- 人工审核高置信度样本

### Phase 3：模型训练（2周）
- Text/决策 Transformer 多模态训练
- 知识蒸馏：小模型压缩大模型推理逻辑
- Regime 分支：牛市/熊市/震荡分别训练

### Phase 4：集成 P4（1周）
- `g4_screener.py` 独立脚本
- `p4_dispatcher.py` 调度 G4
- `synthesize.py` 综合评分加入 G4 权重

## 七、与现有策略的关系

```
现有 P4 权重（超强牛市）
  G1 趋势跟随: 80%
  G2 低吸回踩: 10%
  G3 ML概率:   10%

加入 G4 后（专家决策）：
  G1 趋势跟随: 60%
  G2 低吸回踩: 10%
  G3 ML概率:   10%
  G4 专家蒸馏:  20%
```

G4 提供**人类专家的判断框架**，与纯量化的 G1/G2/G3 正交，可叠加。

---

## 八、关键风险与应对

| 风险 | 应对 |
|------|------|
| 视频内容质量参差 | 只选经过市场验证的盈利交易员 |
| 标注成本高 | LLM自动标注 + 人工抽检 |
| 专家决策与当前市场不适配 | Regime-aware routing |
| 模型推理延迟高 | 知识蒸馏压缩模型，batch 推理 |
