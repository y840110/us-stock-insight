# exp9 — G4 专家策略蒸馏实验

> 用于：视频理解 + 专家决策框架蒸馏

## 背景

从方方土价格行为学视频课中，提取专家（阿尔布鲁克斯）的决策框架。

核心问题：视频内容有 K 线图表，纯文字转写丢失视觉信息。

## 方案

**视觉指纹分段**：视频抽帧 → pHash 去重 → 自适应场景分段 → Vision模型理解画面 → 对齐文字 → 结构化决策框架

详见：`docs/视觉指纹分段方案.md`

## 最终目标

**输入**：K线数据 或 截图
**输出**：涨跌概率判断 + 投资决策建议

通过蒸馏方方土等专家的交易框架，构建 G4 专家决策引擎，能够：
1. 理解K线形态（支撑/阻力/趋势线/突破/陷阱）
2. 结合市场环境（趋势/震荡/背离）
3. 给出具体交易信号（买入/卖出/观望）+ 概率置信度
