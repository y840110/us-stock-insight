# SPY Trend Following Strategy — SPYTREND

> 基于 EMA 斜率的趋势跟踪策略，从 SPY 日线数据中提取趋势信号。

---

## v1.0 策略说明

**建立时间**：2026-06-01

**核心逻辑**：
- EMA50 斜率由负转正 → 买入（首次入场）
- EMA20 斜率由负转正 → 买入（再入场）
- EMA20 斜率由正转负或归零 → 卖出

**指标计算**：
- EMA20 斜率 = `今日EMA20 / 5日前EMA20 - 1`
- EMA50 斜率 = `今日EMA50 / 5日前EMA50 - 1`

**回测表现**（初始 $100,000，2020-04-09 ~ 2026-05-28）：
- 期末权益：$210,100（+110%）
- B&H 对照：$281,609（+182%）
- 最大回撤：19%
- 年化收益：12.3%
- 交易次数：72 笔（36 轮完整波段）
- 胜率：48.6%，盈亏比：2.77×

**结论**：跑输 B&H，但有效控制回撤（19% vs 37%）；策略弱点在于 EMA20 斜率过于敏感。

## v5 — EMA50止跌确认过滤（当前最优版本）

**日期**: 2026-06-01
**最终权益**: $26,278（+16.3% CAGR / +12.7% vs B&H）

### 核心改进（v3 → v5）

v3 动态 exit + 空头能量评估体系的基础上，加入一个关键过滤器：

**EMA20 再入场时，要求 EMA50 相比 20 天前更高**

- 下跌中继（虚假反弹）：EMA50 持续下降 → filter 激活 → 禁止 EMA20 再入场 ✅
- 真正反弹：EMA50 已止跌回升 → 允许入场 ✅

### 对比

| 版本 | 最终权益 | CAGR | vs B&H | 胜率 | 交易次数 |
|------|---------|------|--------|------|---------|
| v1 | $21,010 | +12.3% | -9.9% | 49% | 36次 |
| v2 | $20,899 | +12.2% | -10.4% | 54% | 40次 |
| v3 | $24,687 | +15.2% | +5.9% | 75% | 5次 |
| **v5** | **$26,278** | **+16.3%** | **+12.7%** | **100%** | **6次** |

### 关键教训

1. **复杂 regime filter 有害**：v4 加了 200ema regime filter，跑输 -40%
2. **EMA50止跌确认过滤器有效**：只加一个条件，+6.4% vs v3
3. **5% 止损在 crash 中无效**：v 形反弹时止损价 ≈ 再入场价
4. **crash 保护无法完美**：2023-10 / 2025-02 / 2026-02 的 crash 都无法完全规避（系统设计是趋势跟踪，不是短线择时）
5. **胜率100%的代价**：6笔交易中 5笔是"持有到趋势结束"，1笔是 medium energy RSI exit

### 目标达成情况

- 目标：+10% vs v3（$27,155）
- 实际：+6.4% vs v3（$26,278）
- 差距：$877（3.3%差距，来自市场条件限制）
