### 第 2 步：视频分析（全帧提取 + 图形比对）

**核心思想**：提取视频所有画面帧，通过图形比对合并相同/相似画面，建立画面与字幕的精确时间映射。

#### 2.1 提取所有画面帧
```bash
mkdir -p /tmp/frames_pXX
ffmpeg -i "视频路径" -vf "fps=1" /tmp/frames_pXX/frame_%05d.jpg -y
```
- `fps=1` 表示每秒1帧（可根据视频长度调整，短视频用更高fps）
- 帧保存在 `/tmp/frames_pXX/`

#### 2.2 图形比对去重（Python）
使用感知哈希（pHash）比对所有帧图像，合并相似帧：

```python
import os
import imagehash
from PIL import Image
from collections import defaultdict

def group_similar_frames(frame_dir, hash_size=8, threshold=5):
    """按感知哈希分组相似帧，返回 {帧编号: [(帧路径, 开始时间, 结束时间)]} """
    frames = sorted([f for f in os.listdir(frame_dir) if f.endswith('.jpg')])
    groups = defaultdict(list)
    prev_hash = None
    prev_frame = None

    for i, fname in enumerate(frames):
        fpath = os.path.join(frame_dir, fname)
        h = imagehash.phash(Image.open(fpath), hash_size=hash_size)

        if prev_hash is not None and h - prev_hash < threshold:
            # 与前一帧相似，合并到同一组
            groups[len(groups) - 1].append((fpath, prev_time, curr_time))
        else:
            # 新画面组
            groups[len(groups)].append((fpath, curr_time, None))

        prev_hash = h
        prev_frame = fname

    return groups
```

**合并规则**：
- 感知哈希差异 < 5 → 判定为同一画面
- 每组保留代表帧（第一帧），记录起止时间
- 少于3帧的极短画面组可忽略

## 🚨 中断与限流规则

### Vision API 限流
- **规则**：Vision API 每 5 小时更新 1 次（rate limit）
- **检测**：子 Agent 运行时如遇到 rate limit 错误，立即停止
- **报告**：停止后立即向主 session 报告当前中断位置（PXX）
- **恢复**：等待限流窗口结束后继续

### Vision API 子 Agent 网络问题（重要！）
- **问题**：`minimax__understand_image` 通过 OpenClaw MCP 调用，子 Agent 报 `Not connected`
- **现象**：主 session 正常，子 Agent 全部失败
- **原因**：子 Agent 沙箱环境网络隔离，无法访问 MCP stdio 连接
- **解决方案**：使用 `exp9/scripts/batch_vlm.py` 直接调用 VLM API
  - 端点：`POST https://api.minimaxi.com/v1/coding_plan/vlm`
  - 认证：`Authorization: Bearer {MINIMAX_API_KEY}`
  - 绕过 MCP，直接 HTTP 调用，稳定可靠

### Whisper CPU 限制
- **规则**：Whisper CPU 推理有超时/内存限制
- **实测结果**：
  - 4 分钟段：仍会被 SIGKILL（危险）
  - **2 分钟段**：安全，tiny 模型约 2-3 分钟完成
- **最终方案**：每段 2 分钟，逐个顺序转写，禁止并行
- **症状**：进程被系统终止，无输出
- **解决方案**：
  - 使用 `tiny` 模型
  - 音频 2 分钟分一段（安全边界）
  - 长视频先切分为 5 分钟视频段，每视频段再切 2 分钟音频

### 子 Agent 长时间运行
- 单课学习超过 1.5 小时无响应 → 检查是否卡住
- 可选择终止并继续下一课

#### 4. Direct API 调用 Vision（解决子 Agent MCP 问题）
**问题**：`minimax__understand_image` 通过 MCP 调用，子 Agent 报 `Not connected`
**解决**：直接调用 MiniMax VLM API

```python
import urllib.request, json, base64

API_KEY = "sk-cp-..."  # MiniMax Token Plan Key
API_HOST = "https://api.minimaxi.com"
URL = f"{API_HOST}/v1/coding_plan/vlm"

def call_vlm(image_path, prompt, retries=3):
    with open(image_path, 'rb') as f:
        img_base64 = base64.b64encode(f.read()).decode()
    payload = {
        "prompt": prompt,
        "image_url": f"data:image/jpeg;base64,{img_base64}"
    }
    req = urllib.request.Request(
        URL,
        data=json.dumps(payload).encode(),
        headers={
            "Authorization": f"Bearer {API_KEY}",
            "Content-Type": "application/json"
        },
        method="POST"
    )
    with urllib.request.urlopen(req, timeout=60) as resp:
        result = json.loads(resp.read())
        return result.get("content", "")
```

**脚本**：`exp9/scripts/batch_vlm.py` — 批量处理所有帧组
