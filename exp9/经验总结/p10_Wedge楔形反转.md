## 二、上升楔形 Rising Wedge（看跌）

### 形态特征
- 两条趋势线向上倾斜，向右收敛
- 价格三次向上推动（1、2、3 Push），每次高点抬升越来越小
- 第三次推高后无力创新高，跌破下轨趋势线

### TSLA 日线案例
```
特征：
- 三推楔形顶（1→2→3，每推幅度递减）
- 价格无力突破前高
- 大阳线后迅速回落
- 跌破楔形下轨 → 入场做空
- 止损：楔形最高点上方
- 目标：Measured Move（等距移动目标）
```

### 三推楔形反转原理
> Brooks 定理：楔形三推后经常发生反转

- 每次上推幅度越来越小 = 买方动能衰竭
- 第三次推高失败后，空头开始主导
- 跌破楔形下轨 = 趋势从多转空确认

---

## 三、下降楔形 Falling Wedge（看涨）

### 形态特征
- 两条趋势线向下倾斜，向右收敛
- 价格三次向下试探（1、2、3 Push），每次低点点位越来越浅
- 第三次下探获得支撑，突破上轨趋势线

### 交易逻辑
```
入场：突破上轨趋势线后买入
止损：楔形最低点下方
目标：等距移动目标（Measured Move）
```

---

## 四、三推反转规律（Brooks 核心）

> **"三推之后经常反转，但不是每次都反转"**

### 三推后的反转类型

| 场景 | 结果 | 概率 |
|------|------|------|
| 三推在楔形内 | 反转概率高 | 60%+ |
| 三推在通道内 | 通常延续 | 70%+ |
| 三推在旗形中 | 趋势延续 | 更高 |
| 三推后超出通道 | 通常失败 | 低 |

### 关键区别
- **超出（Overshoot）**：三推超出通道/前高 → 反转失败，趋势继续
- **达不到（Undershoot）**：三推未触及目标 → 反转概率高

## 五、好 Wedge vs 坏 Wedge

| 判断维度 | 好 Wedge（反转） | 坏 Wedge（趋势延续） |
|---------|-----------------|---------------------|
| 三推幅度 | 每次递减，衰竭明显 | 每次幅度相近，趋势健康 |
| 价格位置 | 远离前一波段 | 在前波段内部 |
| 成交量 | 三推时缩量 | 跟随时放量 |
| 形态外观 | 收敛明显 | 形态不规则 |
| 出现位置 | 趋势末期/极端位 | 趋势中途 |

## 六、入场策略

### 入场点分类

1. **第一入场点（First Entry）**
   - 楔形下轨/上轨突破瞬间
   - 风险：假突破
   - 优势：止损窄

2. **第二入场点（Second Entry）**
   - 突破后的回踩确认
   - 风险：错过机会
   - 优势：更高确定性

### Measured Move（等距测算目标）

```
测算方法：
- 楔形起点到颈线的距离
- 从突破点向上/下等距投射

案例：
- 楔形高度 = 10元
- 突破点 = 100元
- 第一目标 = 110元
- 实际走势：最高112元 ✓
```

## 七、实战要点速记

1. **Wedge = 三推反转**：楔形内的三推后经常反转
2. **上升Wedge看跌，下降Wedge看涨**：方向与形态倾斜相反
3. **动能递减**：三推幅度越来越小 = 衰竭信号
4. **超出 vs 达不到**：达不到目标 → 反转概率高
5. **Nested Wedge**：多重楔形叠加，目标逐级测算
6. **Parabolic Wedge**：极端加速后的楔形，高胜率反转
7. **好Wedge vs 坏Wedge**：衰竭明显=好Wedge，趋势健康=坏Wedge
8. **第一入场 vs 第二入场**：激进选第一，保守选第二
