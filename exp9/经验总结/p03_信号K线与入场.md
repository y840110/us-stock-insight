## 一、本章核心知识点

### 1. 信号K线（Signal Bar）— 最核心概念

**定义**：能够触发交易入场的K线。

| 质量 | 特征 |
|------|------|
| **好的做多信号** | 大阳线 + 收盘在最高/高位 + 无上影线 |
| **好的做空信号** | 大阴线 + 收盘在最低/低位 + 无下影线 |
| **差的信号** | 实体很小、十字星、影线很长、收在中间 |

**关键原则**：信号K线本身不是入场的指令，需要等待**触发（Trigger）**。

---

### 2. 入场方法三种

| 方法 | 操作 | 适用场景 |
|------|------|---------|
| **Buy Stop** | 在信号K线高点上方1 tick挂单 | 新手首选，避免假突破 |
| **Market Order** | 信号K线收盘时直接市价入场 | 执行力强的交易员 |
| **Buy Limit** | 在支撑位下方挂单 | 已知支撑位时 |

**Buy Stop 标准操作**：
```
做多：信号K线高点上方1 tick → Buy Stop（等待触发）
止损：信号K线低点下方1 tick
```

**Sell Stop 标准操作**：
```
做空：信号K线低点下方1 tick → Sell Stop（等待触发）
止损：信号K线高点上方1 tick
```

---

### 3. 背景（Context）重于信号（Signal）— 核心原则

**强趋势中**：
- 强上升趋势 → "Always In Long" → 只能做多，不抄底
- 强下降趋势 → "Always In Short" → 只能做空，不追空

**强趋势中的入场**：
- 不需要完美信号，背景已提供足够优势
- 任何入场点都可以用

**震荡区间中**：
- 信号K线质量差，不要追
- 等待突破确认更好

---

### 4. 强趋势 vs 弱趋势的信号K线质量要求

| 趋势强度 | 信号K线要求 | 说明 |
|---------|-----------|------|
| 强趋势 | 不需要完美信号 | 背景已足够 |
| 中等趋势 | 需要较好信号 | 结合位置判断 |
| 弱趋势/震荡 | 必须完美信号 | 否则不做 |

---

### 5. 好的做多/做空信号K线（图解）

**最优做多**：
```
大阳线，收盘在最高，无上影线
→ 所有人都愿意买入
```

**可接受做多**：
```
大阳线，有一点上影线
→ 基本确认多头
```

**差的做多**：
```
实体不够大，上影线较长
→ 需更好的背景支撑
```

---

### 6. 分批建仓（Scaling In）

**定义**：不确定时先用小仓位，确认后再加仓。

**优势**：
- 降低单次错误的风险
- 提高整体容错率
- 让心态更稳定

**应用**：在反转初期使用小仓位试探，验证后加仓。

---

### 7. 低点入场 vs 高点入场

| 入场方式 | 胜率 | 盈亏比 | 适合人群 |
|---------|------|--------|---------|
| 低点入场（支撑位买入）| 高 | 中 | 新手 |
| 高点入场（突破追入）| 低 | 高 | 有经验者 |

**建议**：新手优先选择低点入场（胜率高）。

---

### 8. 等待信号K线失效（Not Entry）

**何时等待**：
- 信号K线形成后，价格没有立即跟随
- 后续没有 Follow-through K线
- 说明信号失效，避免了亏损
