## 核心概念

### 市场周期的四个阶段

Brooks 将市场周期分为 **4 个阶段**，构成一个完整的循环：

```
突破 (Breakout)
    ↓  趋势开始减缓
窄通道 (Tight Channel)
    ↓  回调幅度增大
宽通道 (Wide Channel)
    ↓  趋势动力耗尽
震荡区间 (Trading Range)
    ↓  最终被突破
新突破 (New Breakout) → 循环往复
```

---

## 各阶段价格行为特征

### 1. 突破 (Breakout) — 最强趋势阶段

**K线特征：**
- 连续大阳线/大阴线，几乎无回调/反弹
- K线实体长，影线短
- 重叠极少，垂直方向的强力移动
- 处于 Always In 状态（只能顺势做多/做空）

**实战要点：**
- **Always In Long (AIL)**：突破确认后，市场只允许做多，禁止逆势做空
- **波段为主**：盈亏比可能较低，但胜率极高
- **仓位管理**：止损距离越大，仓位必须越轻
  - 止损5元 → 可买100股（最大亏损500元）
  - 止损10元 → 只能买50股
  - 止损20元 → 只能买25股

### 2. 窄通道 (Tight Channel) — 强趋势阶段

**K线特征：**
- 紧贴上升/下降趋势线
- 回调/反弹非常浅（1-3根K线）
- 高低点仍在抬高/降低
- 通道宽度窄

**实战要点：**
- **顺势波段**：回踩支撑买入，反弹高点做空
- **止损原则**：永远放在起涨点（最低点）下方 / 起跌点（最高点）上方
- **关键信号**：回调失败是买入信号

### 3. 宽通道 (Wide Channel) — 弱趋势阶段

**K线特征：**
- 回调/反弹幅度大（超过5-10根K线）
- 高低点仍在抬高/降低，但速度放缓
- 多空双方都有机会
- 趋势开始接近尾声

**实战要点：**
- **顺势波段为主**：不要轻易逆势
- **支撑位买入**：但要在高位减仓
- **注意见顶信号**：可能出现卖出高潮 (Sell Climax)

### 4. 震荡区间 (Trading Range) — 无趋势阶段

**K线特征：**
- 无明确方向，横向移动
- 在支撑位和阻力位之间波动
- K线频繁重叠
- 多空力量相对均衡

**实战要点：**
- **高抛低吸 (BLSHS)**：下沿买入，上沿卖出
- **止损放大**：假突破多，止损要比趋势中大一些
- **窄区间**：剥头皮利润少，等突破做趋势
- **宽区间**：高抛低吸利润大，可以做
- **持续很久 (>20根K线)**：被突破概率增大，等待突破

## 惯性定律（80%规律）

这是 Brooks 价格行为学的核心：

| 市场状态 | 惯性定律 |
|---------|---------|
| 上涨趋势 | 80%的回调尝试会失败 → 上涨继续 |
| 下跌趋势 | 80%的反弹尝试会失败 → 下跌继续 |
| 震荡区间 | 80%的突破尝试是假突破 → 区间继续 |

**实战含义：**
- 顺势交易 = 相信惯性，胜率高但盈亏比低
- 逆势交易 = 赌惯性失败，需要等明确信号
- 震荡中高抛低吸 = 利用80%的假突破

---

## 止损设置核心原则

### 永远放在起涨点 / 起跌点

**多头止损**：放在突破的**最低点**下方
> "只有最低点被跌破，才能说上涨趋势结束"

**空头止损**：放在突破的**最高点**上方
> "只有最高点被突破，才能说下跌趋势结束"

**已持仓**：可移动止损到新的起涨点上方（追踪止损）

## 多时间框架共振

| 级别关系 | 周期表现 |
|---------|---------|
| 大级别突破 | → 小级别是窄通道 |
| 小级别宽通道 | → 大级别是窄通道 |
| 更小级别 | 是宽通道 |

**实战应用**：主要交易级别需参考大一个级别的结构

## 二元决策框架

Brooks 的核心框架：**每个时刻只判断两件事**

1. **趋势还是震荡？**
   - 趋势 → 顺势交易（只在回调结束时入场）
   - 震荡 → 高抛低吸（或等待突破）

2. **Long 还是 Short？**
   - Always In Long → 只做多
   - Always In Short → 只做空
   - WATCH → 不确定时不做

## 周期演变规律

**从强到弱的必然性：**
```
突破 → 窄通道 → 宽通道 → 震荡区间
```

**触发事件：**
- **连续大阳线后** → 可能是 Sell Climax（卖出高潮），趋势不可持续
- **连续大阴线后** → 可能是 Buy Climax（买入高潮），趋势不可持续
- 趋势越强 → 转变为通道越快

**Measured Move（测量移动）：**
- 真突破后，目标 = 区间幅度翻倍

## K线形态分析（3个场景）

### 场景1：强劲突破后的窄通道（BTC 4H）

**形态描述：**
- 连续3-5根大阳线突破前高（突破阶段）
- 之后紧贴EMA20小幅回调（窄通道）
- 每次回调1-3根K线即止跌

**判断：**
- 周期：多头窄通道
- 信号：Always In Long
- 入场：回踩前一根信号K线低点买入
- 止损：放在突破起涨点（最低点）下方

**结果：** 顺势波段持有，盈亏比3:1以上

---

### 场景2：宽通道中的假突破（纳指期货）

**形态描述：**
- 上涨趋势中高点逐步抬高（宽通道）
- 价格触及通道上沿后反转
- 反转向下突破通道下沿

**判断：**
- 周期：空头宽通道（趋势减弱）
- 信号：等待突破确认
- 入场：等价格收在通道下沿下方后追空
- 止损：放在通道下沿上方（假突破止损小）

**结果：** 突破确认后做空，趋势延续

---

### 场景3：长期震荡区间（黄金日线）

**形态描述：**
- 价格在 $1900-$2000 区间震荡超过20根K线
- 多次触及上下沿后反转
- 第三次触碰下沿时出现长下影线

**判断：**
- 周期：震荡宽区间
- 信号：高抛低吸
- 入场：下沿做多，上沿做空
- 止损：区间幅度约$100，止损放大至$105

**注意：** 震荡越久，被突破概率越大，可同时准备突破策略
