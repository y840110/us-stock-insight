## 一、核心概念速查表

| 概念 | 说明 | 重要性 |
|------|------|--------|

## 二、入场决策矩阵

### 背景质量 × 信号K质量

|  | 好信号K | 差信号K |
|--|---------|---------|
| **好背景** | ✅ 积极入场 | ⚠️ 谨慎入场 |
| **差背景** | ⚠️ 禁止/跳过 | ❌ 绝对禁止 |

**背景质量判断**：
- 好背景：5+连续K线同向收盘在高位/低位，趋势健康
- 差背景：强趋势80%延续，追反转胜算极低

---

## 三、入场方式体系（Al Brooks）

### 4种基本入场方式（seg_1~2）

1. **Buy Stop**（突破Stop）
   - 在信号K高点上方用Stop Buy单入场
   - 条件：信号K上方有空间，好背景+好信号

2. **Buy Limit**（限价买单）
   - 在回调支撑位挂Limit Buy
   - 适合：强势趋势中等回撤（ bread & butter 思维）

3. **买收盘**（Buy Close）
   - 信号K收盘确认后，市价入场
   - 适合：信号明确，趋势健康

4. **EMA20/均线入场**
   - 价格回撤至EMA20附近时入场
   - 适合：波段交易，趋势跟踪

### 顺势交易入场优先顺序（seg_2）

```
好背景 + 好信号K：
  ① Buy Stop（突破追入）
  ② 买收盘（顺势确认）
  ③ Buy Limit（回调入场）
  ④ EMA20回撤买入
```

## 四、系统交易 vs 主观交易

### Brooks 的定位（seg_3）

- Al Brooks 是**主观交易者**
- 但他花了 **10万+小时** 研究和编写指标/代码
- 本质：将主观交易经验系统化、规则化

### 两种风格的对比（seg_3）

| 维度 | 系统交易 | 主观交易 |
|------|---------|---------|
| 入场依据 | 规则触发，100%客观 | 形态识别+背景判断 |
| 灵活性 | 低，规则固定 | 高，可适应市场变化 |
| 执行 | 无情绪干扰 | 需要纪律和经验 |
| 前提 | 需要有正期望系统 | 需要长期训练 |

### 结论

> **系统化与主观交易无优劣之分**  
> 专注一种方法并精通，都能赚钱  
> Brooks 的框架是"半系统半主观"——用规则识别形态，用主观判断背景

## 五、高胜率突破4要素（seg_3, seg_4）

强势突破的判断标准：

1. **远离之前的区间**：突破前在窄幅震荡，突破时远离
2. **体积足够大**：K线实体大，显示真实卖压/买压
3. **收在最低/最高**：收盘确认日内最强方向
4. **后续有跟随**：下一根K线顺势延续

满足3+要素 → 高胜率突破信号

---

## 六、盈亏比与胜率关系（seg_2）

**核心公式**：数学期望 = (胜率 × 平均盈利) - (败率 × 平均亏损)

**Brooks 案例**（seg_2）：
- 胜率 40%，盈亏比 2:1
- 数学期望 = (0.4 × 2) - (0.6 × 1) = **+0.2**（正期望）

**结论**：
- 40%胜率 + 2:1盈亏比 = 正期望系统
- 不需要追求高胜率（50%+），关键是盈亏比

## 七、实战案例

### 案例1：双顶做空（seg_0）

```
背景：上升趋势见顶
信号：大阴线收在最低（流星线）
入场：Sell Stop 挂在大阴线下方
止损：双顶高点上方
目标：前低（颈线到高点的等距移动）
盈亏比：3-4倍
判断：好背景（趋势顶）+ 好信号K（拒绝形态）→ 入场合理
```

### 案例2：强趋势中的假反转（seg_0）

```
背景：5根连续阳线收盘在高位 = 极强趋势
信号：小实体/十字星 + 长影线 = 弱反转信号
结论：82%规则 → 趋势继续，不做空
替代方案：等回调 Buy Limit（bread & butter）
```

### 案例3：熊旗形态做空（seg_4）

```
背景：紧线后的三推形态（类似熊旗）
入场：在支撑位下方挂Sell Stop
止损：紧线上方
目标：前低或等距移动
条件：需要背景+信号共振
```

## 八、关键规则速记

1. **82%规则**：强趋势80%延续，20%反转
2. **背景优先**：背景差时，好信号K也禁止
3. **Bread & Butter**：强势中等回调挂 Buy Limit
4. **双顶/双底**：颈线入场，3-4倍盈亏比
5. **4要素突破**：远离区间 + 大体 + 收极端 + 有跟随
6. **40%胜率+2:1盈亏比**：正期望系统
7. **系统 vs 主观**： Brooks = 主观框架，系统执行
